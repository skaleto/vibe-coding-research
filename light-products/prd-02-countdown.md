## 1. 产品概述

### 1.1 一句话定义
中国少女风/极简/复古胶片风的倒数日，把 iOS 桌面变成你的纪念日仪式感。

### 1.2 差异化定位

| 维度 | 标杆 Days Matter | 本产品 |
|---|---|---|
| 美学 | 工程师审美，界面缭乱 | **小红书少女风 / 极简 / 复古胶片**多套主题 |
| 小组件 | 类型/设计不及格 | **20+ 主题 × 5+ 尺寸 = 100+ 组合** |
| 推广 | 菜单藏自家其他 App 推荐 | **零推广**，全屏纯净 |
| 时间单位 | 仅"X 天" | **天 / 周 / 月 / 年 / 自定义**自由切换 |
| 同步 | iCloud | iCloud + 飞书/钉钉日历同步 |
| 定价 | ¥3/月 订阅 + ¥32 一次性 | **¥3 单主题 / ¥18 全主题永久**（一次性，小猫补光灯模式） |

### 1.3 验证依据

- Days Matter 中国区 App Store 效率榜 **#1**，月下载 90 万 / 月入 **$60K**
- 监管几乎为零（无算命/医疗/金融触发点）
- 用户痛点真实（豆瓣"已解决：ios 有无除 days matter 以外好看简洁的倒数日 app"）
- ¥18 永久符合"小猫补光灯"成功公式（低决策门槛 + 一次性买断）

## 2. 目标用户画像

### 2.1 「想要桌面有仪式感的少女」（核心）
- **画像**：18-30 岁女性，iPhone 用户，小红书重度
- **触发**：刷到博主"超美倒数日小组件"截图
- **痛点**：Days Matter 太丑、Countdown Buddy 主题少
- **付费心智**：「为了好看的截图我愿意付 ¥18」
- **核心价值**：**桌面截图美感 + 小红书可分享**

### 2.2 「需要追工作 deadline 的极简党」
- **画像**：25-35 岁，知识工作者
- **痛点**：日历提醒太分散，想要"焦点视图"
- **付费心智**：极简党通常愿付一次性永久
- **核心价值**：**纯粹、零打扰、可同步飞书/Outlook**

### 2.3 「文艺胶片纪念党」
- **画像**：25-35 岁，纪念恋爱/结婚/孩子出生/旅行
- **触发**：纪念日临近
- **付费心智**：仪式感的延伸（已经买了周边周边周边）
- **核心价值**：**复古胶片美学 + 海报分享朋友圈**

## 3. 核心用户故事

### 用户故事 1：林同学，22 岁

> 看小红书一个博主晒"我的考研倒数 100 天"小组件，超治愈。点进评论问用的什么 App，博主说"倒数日 Pro，主题永久 ¥18"。下载后我选了"复古胶片风"主题，把研究生入学日期设上，把组件挂在桌面正中。每天解锁手机第一眼就看到。¥18 也不贵，关键是发到我自己小红书 → 朋友评论"这是什么 App"，又给我带来 50 个粉。

### 用户故事 2：王先生，30 岁，远程工程师

> 我有 8 个 deadline 要追：女儿生日、结婚纪念日、年度 review、3 个客户上线日期、护照过期、车险续保。用 Outlook 太重，用 Apple 日历看不到全局。这个 App 让我把 8 件事挂在桌面，扫一眼就知道。¥18 一次性，比订阅式 Notion 模板划算多了。

## 5. 信息架构

```
启动页（首次引导：3 张截图教学）
  └─→ 首页
        ├─→ 列表/卡片视图切换
        ├─→ + 新建倒数日
        │     └─→ 输入页 ── 类型/颜色/图标/提醒 ── 保存
        ├─→ 详情页
        │     ├─→ 编辑 / 删除 / 复制
        │     └─→ 一键生成海报 ── 分享
        ├─→ 主题市场（5 套预览 → 付费）
        └─→ 设置（iCloud / 通知 / 关于）
```

## 6. 主题美学方向（关键差异化）

| 主题包 | 风格描述 | 目标用户 | 设计参考 |
|---|---|---|---|
| **少女心** | 粉嫩渐变 + 手写体 + 蝴蝶结/星星图标 | 18-25 女性 | 小红书"千禧少女" |
| **极简** | 黑白灰 + 极简衬线 + 一根分隔线 | 25-35 知识工作者 | Things 3 / Bear |
| **复古胶片** | Kodak/富士滤镜 + 像素字体 + 老照片质感 | 25-30 文艺 | VSCO / 黄油相机 |
| **国风** | 水墨 + 宋体竖排 + 落款印章 | 25-35 文化爱好者 | 节气 App |
| **赛博朋克** | 霓虹 + 等宽字体 + 网格背景 | 18-30 极客 | TidByt |

**核心**：每个主题包必须**让用户截图发小红书/朋友圈有面**。每套主题准备 3 张"种草截图" → 自动注水主题市场 → 引导付费。

## 7. 定价策略

| SKU | 价格 | 包含 | 设计目的 |
|---|---|---|---|
| 免费 | ¥0 | 3 个倒数日 + 默认主题 + 小组件基础 | ASO 流量入口 |
| 单主题 | **¥3** | 一套主题永久解锁 | 试水冲动 |
| 全主题永久 | **¥18** ⭐ | 全部主题 + 未来更新 + 无广告 | **主力 SKU** |
| 永久 Pro | ¥38 | 全主题 + iCloud 高级同步 + 优先客服 + 测试新主题 | 信仰用户 |

**关键转化点**：
- 免费用户最多 3 个倒数日 → 第 4 个触发付费
- 默认主题刻意"工程师审美" → 主题预览页 5 套美图让用户跳到付费

## 9. 技术选型

| 层 | 选型 |
|---|---|
| 前端 | **iOS Swift + SwiftUI**（核心战场）；安卓 Compose（次要）|
| 后端 | 极轻，仅做主题包下载 + 付费验证 → Cloudflare Workers + R2 |
| 数据库 | 本地 SwiftData / Core Data + iCloud Sync |
| 桌面小组件 | **WidgetKit**（iOS 14+） |
| Apple Watch | WatchOS Complications（V3） |
| 付费 | Apple IAP（主要） + 微信支付（安卓） |
| 分析 | Firebase + 友盟 |

**关键技术资产**：
- 主题包加密 + 校验机制（防破解）
- 小组件渲染优化（节省电量）
- 海报生成（前端 Canvas 渲染）

**成本估算**：单用户全生命周期成本 < ¥0.5（无 LLM 调用，纯本地）。**毛利率 99%**。
