# AI 起名小程序矩阵 — 市场调研报告

**调研时间**：2026-05-27
**研究对象**：AI 起名小程序 5 个子产品矩阵（宝宝 / 公司 / 宠物 / 游戏 ID / 笔名）
**目标市场**：中国国内（微信小程序 + iOS 国区 + 安卓）
**差异化抓手**：真 AI 释义（GPT-4o / Claude 生成名字 + 出处 + 八字契合度）+ 海报美感 + 极速生成

## 一、市场规模与用户基数

### 1.1 三大平台搜索量级判断

直接查询百度指数 / 微信指数 / 抖音指数官方平台需登录鉴权，本报告通过多个来源交叉判断量级。

| 关键词 | 量级判断 | 推断依据 |
|---|---|---|
| 宝宝起名 | **百度指数日均 PC+移动 5,000-10,000+；微信指数月活搜索数百万级** | 美名腾累计使用 5-8 亿次（[meimingteng.com](https://m.meimingteng.com/m/intro.aspx)）；起名通 10 年服务 11 万+ 宝宝（[qimingtong.com](https://www.qimingtong.com/about)）；2016-2018 起名通数据库覆盖 1,800 万新生儿姓名（[36kr Pitchhub](https://pitchhub.36kr.com/project/1679762910778120)）；2024 年中国每年出生人口约 900 万 → 30%-50% 家长有付费/工具起名需求 |
| 公司起名 | **百度指数日均 PC+移动 2,000-4,000；长尾"公司核名"+"工商核名"叠加** | 2024 年全国新登记企业约 800 万家（市场监管总局公开数据），平均每天 2.2 万家新公司核名 |
| 宠物起名 | **百度指数日均数百-千级，相对偏低；但小红书 300 万+ 宠物笔记**（[数英 7000 字宠物文](https://www.digitaling.com/articles/860964.html)） | 2023 年中国宠物市场 2,977 亿元；近 1 年小红书宠物笔记累计 300 万+；社交平台占据宠物起名讨论 |
| 网名 / 游戏 ID | **百度指数日均 PC+移动 10,000+，但客单价极低** | 至和名字网 / 起王名 / 千古名等大量站点常年 SEO 投放；王者荣耀 / LOL 改名卡需求支撑长尾 |
| 笔名 / 自媒体号 | **百度指数 1,000-2,000；微信公众号注册量 2,000 万+** | 知乎专栏 / 简书 / 小红书账号定位文章长期高阅读量 |

### 1.2 量级排序与含义

按搜索体量 + 付费意愿综合排序：
**宝宝起名 ≫ 公司起名 > 网名 / 游戏 ID > 宠物起名 ≈ 笔名**

宝宝起名是唯一一个"高频搜索 + 高付费意愿 + 高消费金额"三高赛道；网名 / 游戏 ID 是"高频搜索 + 低付费意愿 + 极低客单价"；其余三者中等偏小。

### 2.3 宠物起名 / 网名 / 笔名

**宠物起名**：未发现头部独立 App。流量在小红书 / 知乎 / 起名网杂项栏目分散。例如「[宠物取名](https://m.yw11.com/a/chongwuqiming/)」、「[农历网宠物名字大全](https://m.nongli.com/qm/chongwu/6509.html)」、「[起名网宠物频道](https://www.threetong.com/qiming/chongwu/)」均为 SEO 内容站，没有 AI 个性化产品。

**网名 / 游戏 ID**：[起王名 qiwangming.com](https://www.qiwangming.com/) 等在线工具站长期占据 SEO 流量但无 App 化；"特效文字生成器 / 花样网名生成器"是主导形态。商业化弱（流量大但客单价 ¥0-5）。

**笔名 / 自媒体**：完全无独立工具产品，全部依赖手工咨询或 ChatGPT 通用对话。

## 三、用户痛点（真实原话/问题摘录）

来自小红书 / 知乎 / 微信开放社区的真实用户讨论：

1. **「现在玩游戏起 ID 的难度很高，稍微热门一点词大家都能想到，很容易就遇到『您所输入的昵称不可用』，最后改来改去十几遍，心态都要崩了」**（[知乎 王者 ID 谐音梗](https://zhuanlan.zhihu.com/p/344813363)）

2. **「核名是注册公司中最难的一关，特别是在上海，名字的重复率高，创业者容易卡在名字上」**（[知乎 上海注册公司核名](https://www.zhihu.com/question/56234298)）—— 公司起名的核心痛点不是"好听"，而是"工商不驳回"

3. **「字号的核准规则是拆分查核，如果一个字号被拆分为多个字组合时，其中有任意一个被占用，整个字号就不能使用」**——创业者真正需要的是"实时核名 + AI 重排重组"而不是"诗经里挑两个字"

4. **「五格剖象法属于近代日本学术范畴，其评分标准主观性极强，同一汉字在不同软件上的笔画计算方法完全不一样，得出来的成绩偏差高达几十分」**（[博客园 2026 评测](https://www.cnblogs.com/deepagents/p/19989632)）—— 用户对评分软件的不信任

5. **「大多数价格虚高的起名商人，往往都是购买低价的起名软件后花重金做竞价排名推广」**—— 用户对"假大师 + 软件套壳"的反感

6. **「家长普遍出现三大痛点：一是无法快速判断机构是否正规，二是难以衡量老师水平与案例真实性，三是担心付款后遭遇『模板化』交付、售后失联」**（[博客园 2025-11 评测](https://www.cnblogs.com/pinpaituijan/p/19189992)）

7. App Store 用户 ted 君：**「生成的名字很惊艳，完全符合期望，有内涵有文化」**—— "诗词出处 + 释义"是真正的差异化卖点

8. App Store 用户 duolimbo：**「希望支持单字名字、姓氏相关含义」**—— 当前竞品的功能盲点

9. 应用宝用户对起名有福：**「想看宫位分析必须写评论才解锁」**—— 反感套路化付费墙

10. 小红书行业：**「宝宝起名收费 198-598 元，398 元销量最好。三个手机一天三单，10-30 分钟工作就能赚 1,000 元」**（[知乎](https://zhuanlan.zhihu.com/p/656680635)）—— 验证客单价区间与暴利空间

## 六、国内合规审查（关键风险点）

### 6.1 微信小程序规范红线（重度风险）

微信开放社区多次官方回复明确：**「涉及算卜算运势、算命、付费取名等内容，属于平台未允许内容」**（[算卜算运势官方说明](https://developers.weixin.qq.com/community/develop/doc/000082c0f88640f4b490809316b009)）。

具体案例：
- 开发者 wxdccc3bce2d13fd96 提交免费起名小程序，**已移除付费 + 改吉凶为打分**，仍被驳回（[原帖](https://developers.weixin.qq.com/community/develop/doc/00040a7ec0c750abff71a31886b400)）。官方回复三大原因：①隐私协议默认勾选；②类目应放"信息和资讯服务"；③涉及算卜算运势 / 算命 / 付费取名
- 八字排盘小程序「子不语」二次申诉均被驳回（[原帖](https://developers.weixin.qq.com/community/develop/doc/000ca275f788f0aa184d7726b51400)）
- 用户 Gonepoo 报告：拥有 2000+ 用户的占卜小程序被强制下架（[原帖](https://developers.weixin.qq.com/community/develop/doc/000a44d7fe006840f859648095b400)）
- 「面相研究院」小程序因「分销诱导 + 测试类内容」被整改（[伙伴猫案例](https://www.huobanmao.com/case/12756.html)）

**绕开微信红线的实操方案**：
1. **去掉「算命/八字吉凶/打分」字眼**，改为"诗词出处推荐 + 寓意解释 + AI 生成"
2. 不主动展示"五行 / 命理 / 旺财 / 转运"——这些词出现就极有可能被秒驳
3. 类目选「教育 - 教育工具 / 文化艺术」而非「生活服务 - 命理」
4. 核心广告语避免「测算」「准/不准」「大师推荐」，用「AI 生成名字 + 美图海报」中性表述
5. 隐私协议必须用户主动勾选

### 6.2 iOS 国区合规（中度风险）

- **2024-04 起所有 App Store 国区上架必须有 ICP 备案号**（[OSCHINA](https://www.oschina.net/news/260160)），起名类工具 App 个人开发者需以企业主体或个人 ICP 备案，时间 7-30 天
- 苹果对"封建迷信"严打程度低于微信，但**避免在 App 介绍 / 截图中出现"算命/八字/风水/凶吉"**
- 现有起名 App（美名腾、起名有福、宝宝起名大师）能稳定运营 → 合规可行，但要小心 IAP 退款投诉率（黑猫投诉 / 12315 是真实风险）

### 6.3 安卓多渠道（低度风险）

应用宝 / 华为 / 小米 / OPPO / VIVO 审核标准比微信宽松，"宝宝起名 - 国学诗词版"主流允许；但需保留备案号 + 增值电信资质。

### 6.4 综合判断

**最安全策略**：以 iOS App + 安卓应用市场为主力，微信小程序做"AI 海报生成器"等轻量级附属入口（避开"起名"敏感词）。微信不要做主战场。

## 七、6 月预期 MRR 估算

按 30 天产品上线、单产品 0 推广预算 + 自然流量 / 小红书种草 + 个人 IP 起号假设：

### 7.1 三档情景

| 情景 | 假设条件 | 6 月预期 MRR（5 产品合计）|
|---|---|---|
| **保守**（70% 概率）| 1-2 个产品上线，仅 iOS + 应用宝；小红书 / 知乎 0 推广；自然 ASO 长尾流量为主 | **¥3,000-8,000 / 月** |
| **中性**（25% 概率）| 3 个产品（宝宝 + 公司 + 网名/游戏 ID）；小红书 10-20 篇内容种草；ASO 持续优化 | **¥15,000-30,000 / 月** |
| **乐观**（5% 概率）| 全部 5 产品上线；小红书爆款笔记 1-2 个；ASO 进入"AI 起名"长尾词前 3 名；有少量 KOC 转发 | **¥50,000-100,000 / 月** |

### 7.2 估算依据

- 宝宝起名大师（¥18-58 IAP）App Store 51 条评分，按"30:1 评分:付费用户"估付费约 1,500 人 / 累计 → 月均若 100 付费 × ¥38 = ¥3,800
- 起名有福 2,145 条评分 → 累计付费用户估 6 万+ → 单产品月均 ¥10K-30K 可能
- 小红书起名"单号月入 1-2 万元"为偏高自报数据，存在「教程营销」夸大水分
- 国内轻量 App 净利率按 15-25% 做保守敏感性测算；这是模型假设，不是起名赛道实证。若 ¥30K MRR，实际净利可能只有约 ¥6-8K

### 7.3 隐性成本

- GPT-4o / Claude API 成本：每个完整"30 个名字+诗经出处+释义+海报"约 ¥0.3-0.8 → 占毛利 1-2%
- 苹果 30% 抽成 + 退款 5-15%
- 小红书 / 抖音 投放 / 达人 → 进入达 ¥10K+ MRR 后必须叠加

## 八、关键洞察与决策

### 8.1 5 个子产品优先级排序

| 优先级 | 子产品 | 推荐理由 |
|---|---|---|
| ⭐⭐⭐ 第一档 | **宝宝起名** | 搜索量 + 客单价 + 付费意愿三高；竞品定位空隙明显（"诗经/楚辞 AI + 美图海报"市场未饱和）；现有 App 评分 4.6-4.7 验证用户买单 |
| ⭐⭐ 第二档 | **公司起名** | 单客 ¥98-298 ARPU 高、付费决策快（"卡核名"焦虑驱动）；但需要"工商实时核名"API（天眼查 / 企查查接口约 ¥1-5/查询），技术依赖偏重；竞争弱 |
| ⭐ 第三档 | **笔名 / 自媒体** | 完全空白市场；潜在用户基数小但都是付费习惯好的内容创作者；可作为"个人 IP 矩阵"配套产品 |
| ⚠️ 第四档 | **宠物起名** | 客单价过低（¥6-18），且小红书/知乎免费内容已饱和；只适合做 0.5 人小工具引流，不适合主推 |
| ❌ 不推荐 | **游戏 ID / 网名** | 客单价极低（¥1-9），用户付费极差；流量大但变现难；游戏 ID 与游戏内"改名卡"竞争；现有 [qiwangming.com](https://www.qiwangming.com/) 在线工具白菜化 |

### 8.2 最值得先做：宝宝起名

**理由**：
1. **数据验证**：现有头部 App 起名有福 2,145 评分、美名腾 5-8 亿次累计使用——市场已被教育，无需说服
2. **差异化清晰**：现有产品都是"五格剖象 / 周易玄学派"（评分主观、可靠性低），用户原话「评分软件不准」——真 AI（GPT-4o）+ 诗经楚辞出处 + 美图海报 是空白细分
3. **付费曲线健康**：¥18 IAP 试水 → ¥68 主力包 → ¥198 大师包，跨越三个心理价位段
4. **小红书 / 抖音种草分发成熟**：宝宝起名笔记 SEO 流量稳定，KOC 内容结构可参考但需原创表达
5. **微信小程序避雷**：iOS + 应用宝 + 安卓主力，绕开微信"算命红线"
6. **完美契合 1-2 周开发周期**：核心功能 = LLM API 调用 + 名字打分简化版（去掉八字吉凶）+ 海报模板 + 微信支付 / Apple IAP

### 8.3 最该避开：游戏 ID / 网名

**理由**：
- **客单价极低**：用户搜索"网名"通常希望免费拿；竞品 [qiwangming.com](https://www.qiwangming.com/) 全免费 + 广告变现
- **变现路径单薄**：除非进入腾讯王者/和平精英官方改名卡分润，否则无壁垒
- **用户群体冲动消费但极低 LTV**：换 ID 频率极高但单次支付意愿极弱
- **百度指数高但都是「免费查询」意图**

### 8.4 矩阵执行建议

**Phase 1（第 1-2 周）**：宝宝起名 iOS + 应用宝双端上线，¥18/¥68/¥198 三档 SKU，小红书 / 微博自媒体打种子内容
**Phase 2（第 3-4 周）**：复用脚手架开发公司起名（接天眼查核名 API）；笔名做 0.5 人小工具版引流
**Phase 3（第 5-6 周）**：若 MRR 进入 ¥15K+ 中性情景，扩张到抖音 / 小红书付费投放、达人切片合作
**始终避免**：在产品名 / 截图 / 文案中使用"算命 / 八字 / 风水 / 大师 / 转运"等关键词；微信小程序版仅作引流入口、不做主战场。

### 8.5 核心风险预警

1. **AI 名字"过于书面化"**：GPT-4o 默认生成的诗经名常过于生僻（如「皋陶」「莘野」），需要 fine-tune / 后处理过滤
2. **苹果商店退款率高**：评分 4.6-4.7 是表面，看 IAP 退款率（行业常态 8-15%）
3. **微信小程序若做必须避雷**：参考 6.1 五条规则
4. **小红书种草疲劳**：宝宝起名笔记早被"起名副业项目"内卷，新进入者需要差异化角度（如"AI 一秒出诗经名 + 高级感海报"）
5. **存量竞品自我迭代**：起名有福、美名腾随时可能上 GPT API；窗口期估 6-12 个月
