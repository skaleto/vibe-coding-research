## 1. 产品概述

### 1.1 一句话定义
AI 真懂诗经的起名工具 —— 拍下需求，30 秒拿到 10 个有出处的好名字 + 一张可分享朋友圈的"名字证书"海报。

### 1.2 5 子产品矩阵规划

| 优先级 | 子产品 | 客单 | 决策时机 |
|---|---|---|---|
| ⭐⭐⭐ P0 | **宝宝起名** | ¥18-198 | 怀孕 7-9 月 / 出生前 30 天 |
| ⭐⭐ P1 | **公司起名** | ¥98-298 | 注册公司前一周 |
| ⭐ P2 | **笔名 / 自媒体号** | ¥18-68 | 开始做内容创作 |
| ⚠️ P3 | **宠物起名** | ¥6-18 | 领养后 3 天内（小盘子，做引流款） |
| ❌ 不做 | 游戏 ID / 网名 | ¥1-9 | 客单太低，竞品白菜化 |

### 1.3 差异化抓手

| 维度 | 现有竞品（美名腾/起名通/起名有福） | 本产品 |
|---|---|---|
| 名字生成 | 五格剖象（日本近代学派）+ 字典组合 | GPT-4o / Claude 生成 + 真实诗经/楚辞/唐诗出处 |
| 输出形式 | 名字列表 + 评分（用户不信任） | 名字 + 出处 + 寓意 + **可分享美图海报** |
| 用户体验 | 等 30 秒-5 分钟 | **3-10 秒出全部 10 个** |
| 定价 | ¥298-9888（大师包） | ¥68 甜点价（碾压老牌但高于 ¥18 基础包）|
| 文化 | 玄学/算命包装 | 文化/诗词包装（合规友好）|

## 2. 目标用户画像

### 2.1 P0 宝宝起名：「焦虑的高知准妈」
- **画像**：28-35 岁，本科以上学历，一二线城市，怀孕 7-9 月
- **痛点**：长辈推荐的名字"土"，亲戚介绍的大师收 ¥598-3000 但"靠不靠谱说不准"
- **触发**：闺蜜推荐 → 小红书搜"宝宝起名"刷到爆款笔记
- **付费心智**：宁可花 ¥68 自己挑也不愿付 ¥598 给陌生大师
- **核心价值诉求**：「**有出处、有文化、能讲得出来**」（爷爷奶奶要点头）

### 2.2 P1 公司起名：「卡在核名的初创者」
- **画像**：30-40 岁，正在注册公司，已被工商核名驳回 1-3 次
- **痛点**：好名字总有重名；核名拆字算法复杂
- **核心价值诉求**：「**实时核名通过率 + 重组重试**」（不只是"好听"）
- **特殊技术依赖**：天眼查 / 企查查核名 API（¥1-5/查询）

### 2.3 P2 笔名 / 自媒体：「想认真做账号的小红书博主」
- **画像**：25-35 岁，准备开公众号/小红书/B 站，目前账号叫"XX 的日常"
- **痛点**：好名字都被注册，自己想"小清新文艺范"但起出来俗
- **触发**：账号涨粉到 500 时开始考虑"专业化"
- **核心价值诉求**：「**多平台名字统一可用 + Slogan + LOGO 素材**」

## 3. 核心用户故事

### 3.1 P0 宝宝起名（最详）

**用户故事 1：李女士，怀孕 8 月**

> 我和老公姓名都是常见字，但我特别喜欢诗经和楚辞。在小红书刷到一篇笔记说有个 AI 起名工具能 30 秒生成 10 个有出处的名字，¥68 解锁。我下载试了下，输入姓氏"陈"、女宝、五行喜水、希望意境"温润有灵气"。3 秒出 10 个名字：陈知微（取自《诗经·小雅》"知微知章"）、陈在川（孔子"逝者如斯夫"意境）……每个都有 200 字的出处释义。**最打动我的是那张海报：宝宝名字 + 拼音 + 出处 + 中国水墨背景，发到朋友圈，公婆都点赞**。

**Key Insight**：付费转化点不是"名字本身"，而是"海报让我有面子"。

### 3.2 P1 公司起名

**用户故事 2：王先生，连续创业者**

> 注册新公司"杭州 XX 科技有限公司"，前 5 个备选都被工商驳回（"含义不清"、"重复"、"含禁用字"）。在朋友推荐下用 AI 公司起名工具，输入行业（SaaS）+ 偏好（科技感）+ 已被驳的字。AI 给我 20 个候选，**每个都附上"天眼查实时核名结果（通过/驳回原因）"**。¥98 一次性，5 个通过率高的备选名 + 重组重试 5 轮。第二天工商一次过。

**Key Insight**：付费驱动是"核名通过率"而非"好听"，技术门槛在实时 API。

### 3.3 P2 笔名

**用户故事 3：林同学，小红书博主**

> 我账号 500 粉了，想换个文艺名字。用 AI 笔名小程序输入风格（清新/古风/学术），AI 出 30 个组合。¥38 解锁多平台版（小红书/公众号/微博/B 站）+ 生成"开屏 Slogan"+ 一份配套的极简 LOGO 素材 SVG。**省了找设计师 ¥200 + 自己想破头的时间**。

## 6. 核心 Prompt 设计（关键技术资产）

### 6.1 宝宝起名 Prompt（v1）

```
你是一位精通《诗经》、《楚辞》、《唐诗三百首》、《论语》的国学老师，正在为客户起宝宝名字。

# 输入信息
- 姓氏：{surname}
- 性别：{gender}
- 五行喜用：{wuxing}（如：水、火、土、金、木）
- 意境关键词：{vibe_tags}（用户从「温润灵气/坚毅果敢/聪慧博学/活泼可爱」中选）
- 避讳字：{taboo_chars}

# 任务
生成 10 个名字，每个名字必须满足：
1. 真实出处（必须来自上述 4 本经典，引用原句必须能在 ChatGPT 内验证）
2. 字义吉祥、字形美观（避免生僻字如「皋陶」「莘野」）
3. 男孩/女孩适配（女孩侧重柔美灵动，男孩侧重大气方正）
4. 五行属性符合

# 输出格式（JSON）
[
  {
    "name": "陈知微",
    "pinyin": "Chén Zhī Wēi",
    "source": "《诗经·小雅·节南山》",
    "original_quote": "知微知章",
    "explanation": "200 字以内，讲名字寓意 + 出处典故 + 性格期待",
    "wuxing_match": "金/水"
  }
]

# 严格遵守
- 禁止生成生僻字（一二级常用字外）
- 禁止使用「天/帝/王/神」等过大字
- 禁止生成已知重复率高的网红名（梓涵、子轩、紫萱等）
```

### 6.2 公司起名 Prompt（v1）

```
你是工商企业核名顾问，了解《企业名称登记管理规定》。

# 输入
- 行业：{industry}（科技/餐饮/零售/咨询/制造/教育等）
- 公司类型：{type}（有限责任/股份/个体工商）
- 区域：{region}（北京/上海/杭州...）
- 偏好关键词：{keywords}
- 已被驳回的：{rejected}

# 任务
生成 20 个公司名，每个：
- 字号 2-4 字
- 检查已被驳字，避免重复结构
- 给"核名通过率"预估（高/中/低）+ 理由
- 给品牌寓意

# 输出
- 真实可工商使用的字号
- 避免敏感词（"中国""国际""第一"等需要前置审批）
```

### 7.2 转化漏斗设计

```
免费试用（3 个名字） → 看到付费墙 ── 5% 直接买 ¥68
                              └── 看广告解锁第 4-6 个 ──── 进一步引导买 ¥18 → 升级 ¥68
```

### 7.3 关键转化点

- **海报水印**：免费版海报含"AI 起名"水印；¥18 起去水印 → 让用户为"分享面子"付费
- **重新生成限频**：免费用户 1 次/天；付费不限次
- **小红书一键分享套图**：仅 ¥198 包内开放（高客单驱动）

## 9. 技术选型

### 9.1 技术栈（共享脚手架）

| 层 | 选型 |
|---|---|
| 前端 | iOS Swift + SwiftUI（国区主战场）；Taro 多端复用（小程序非起名/拓展可做） |
| 后端 | Cloudflare Workers + R2（成本极低）/ 阿里云函数计算（国内合规） |
| LLM 网关 | OpenRouter / Anthropic Claude API + DeepSeek 兜底（成本对冲） |
| 数据库 | Cloudflare D1 / Supabase（轻量）|
| 付费 | Apple IAP（iOS）+ 应用宝/华为/小米支付（安卓）|
| 图像生成（海报）| 后端 HTML 转图（puppeteer-screenshot）/ 前端 Canvas |
| 分析 | Google Firebase Analytics（海外）+ 友盟（国内）|

### 9.2 API 成本估算

- 单次生成 10 个名字：GPT-4o ~¥0.3 / Claude ~¥0.4 / DeepSeek ~¥0.05
- **建议**：用 DeepSeek 作主力，GPT-4o 作 ¥198 高端套餐"升级感"
- 单用户全流程 LLM 成本 ≤ ¥1.0，毛利率 95%+

## 10. 合规清单（务必逐条 review）

### 10.1 微信小程序（基本不上 / 仅作引流入口）

❌ **不做主战场**。如做，遵守：

| 项 | 规则 |
|---|---|
| 名称 | **不能含"起名/算命/八字/取名/风水"** —— 取"诗经文化助手"、"AI 名字海报"等 |
| 类目 | 「**文化艺术**」或「**信息和资讯服务**」，不要选「生活服务-命理」 |
| 文案 | 删掉"测算/吉凶/大师/转运/旺财"等词 |
| 五行 | 改名"五行喜用 → 字音偏好" |
| 算分 | 完全去掉评分 |
| 隐私协议 | 用户**主动勾选**（默认勾选会被驳）|

### 10.2 iOS 国区

| 项 | 规则 |
|---|---|
| ICP 备案 | 2024-04 起强制，提前 7-30 天准备 |
| 主体 | 企业 / 个体工商户（个人主体已不被支持）|
| 截图 / 描述 | 避免"算命/吉凶/风水"字眼 |
| IAP 价格 | 用阶梯：¥18 / ¥68 / ¥198，不要乱定价 |
| 退款率 | 控制在 <10%，否则审核加严 |

### 10.3 安卓

| 应用商店 | 关键合规 |
|---|---|
| 应用宝 | 备案号 + 增值电信资质 |
| 华为 | 教育 / 工具类目可上，避开"算命"分类 |
| 小米 / OPPO / VIVO | 类似华为 |

### 10.4 内容合规（所有渠道）

- **禁用词**：算命/卜卦/吉凶/凶吉/大师/风水/转运/旺财/化煞/犯太岁
- **替换词**：诗经文化/字义解析/AI 推荐/美图海报/字音偏好
- **海报内容**：禁止出现"测算结果"、"运势预测"，只显示"出处+寓意"
