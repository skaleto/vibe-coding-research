## 1. 产品概述

### 1.1 一句话定义
拍叶子，30 秒诊断病害 + 个性化护理日历 —— 不只告诉你这是什么植物，而是告诉你它**为什么蔫了**和**接下来 30 天怎么浇水**。

### 1.2 差异化定位

| 维度 | 标杆 PictureThis/形色 | 腾讯识花君 | 本产品 |
|---|---|---|---|
| 核心能力 | 通用识别（4000 种）| 免费识别 | **病害诊断 + 个性化护理日历** |
| 输出 | "这是XX花" | "这是XX花" | "你家这盆**因为缺水/光照不足/真菌感染** → 接下来 30 天每周 X 次浇水" |
| 用户场景 | 散步看到陌生植物 | 同上 | **家里养的植物出问题了** |
| 商业模式 | 海外付费/国内免费 | 完全免费 | **¥1 单次诊断 / ¥18 包月护理日历** |
| API 成本 | 自建模型 | 腾讯成本兜底 | **GPT-4V / 智谱 GLM-4V，¥0.05-0.1/次** |

### 1.3 验证依据

- **PictureThis（睿琪海外版）**：海外月流水 **¥8000 万 / 年收入 ¥10 亿**，标杆
- 国内 1.26 亿宠物户 + 千万级花友（小红书"养肉"/"绿萝"标签 300+ 万笔记）
- 形色已转型重度商业化，被用户吐槽"广告太多"，留出空间
- 用户痛点真实：「多肉黑腐了，所有 App 都说是'养护得当'」

## 2. 目标用户画像

### 2.1 「养肉新手」（核心）
- **画像**：22-30 岁女性，租房或小户型，养 3-10 盆多肉/绿萝/龟背竹
- **触发**：植物突然蔫了/叶子发黄/黑腐
- **痛点**：通用识花告诉名字没用，要的是"为啥蔫了怎么办"
- **付费心智**："救命型"消费 → 单次 ¥1-6 极易冲动付费
- **核心价值**：**诊断 + 接下来怎么办**

### 2.2 「阳台菜农」（中价值）
- **画像**：30-50 岁，有阳台/小院，种番茄/辣椒/草莓
- **触发**：果蔬叶子有虫眼/病斑
- **痛点**：百度搜不到准确答案；老人凭经验喷药容易过量
- **付费心智**：「为了我这盆草莓不死可以买月卡」
- **核心价值**：**病虫害诊断 + 用药指导（中性建议）**

### 2.3 「文艺植物党」（轻价值）
- **画像**：25-35 岁，养奇花异草（兰花/铁线莲/食虫植物）
- **触发**：罕见品种养护信息查不到
- **痛点**：通用 App 数据库浅
- **付费心智**：单次诊断 ¥1-6 OK
- **核心价值**：**罕见品种详细资料**

> 我家窗台的玉露最近叶子开始发软变透明，搜小红书也说不清是什么病。打开 AI 植物医生，拍叶子 + 全株照片，¥1 一次诊断。3 秒出结果：**「叶片发软透明 → 浇水过多 + 通风不足 + 真菌感染初期。建议立刻断水 7 天，转移到通风处，喷多菌灵 1:1000 倍液每 7 天一次共 3 次」**。我按建议做了，玉露 2 周后救回来。立刻续费 ¥18 包月版（家里还有 8 盆），给我自动生成"30 天护理日历"，每周提醒该浇水/施肥/转盆。

## 4. 功能清单

### 4.1 MVP（2 周）

| 模块 | 功能 |
|---|---|
| 拍照入口 | 大按钮"拍叶子诊断"，引导拍 1-3 张（特写+全株+环境）|
| 输入补充 | 浇水频率、光照、土壤、症状描述（可选）|
| 诊断结果 | 病因 + 严重程度 + 处理方案（分步） + 预后预测 |
| 护理日历 | 自动生成"未来 30 天每日待办"（浇水/施肥/喷药/移光）|
| 我的植物 | 添加多个植物，每个独立日历 |
| 付费墙 | 免费 1 次/天 / ¥1 单次 / ¥6 包月 / ¥18 包年 |
| 分享 | 一键生成"我的植物医生报告"海报 |

### 4.2 V2

- 拍照搜索（罕见品种）
- 病害百科（200+ 常见病图鉴 + 病例库）

- 通知（明天该浇水了）

### 4.3 V3

## 5. Prompt 设计（关键）

```
你是经验丰富的植物病理学家 + 园艺专家。

# 输入
- 用户上传图片：{image_url}（叶子特写、全株、环境照）
- 浇水频率：{water_freq}
- 光照：{light}
- 症状描述：{description}

# 任务
1. 识别植物品种（学名+俗名）
2. **诊断问题**：列出最可能的 3 个原因（按概率排序）
3. **处理方案**：分步骤、可执行（不超过 5 步）
4. **预后预测**：救活概率 + 多久见效
5. **未来 30 天护理日历**：每日待办（浇水/施肥/光照/喷药）

# 输出格式
{
  "plant_name": "...",
  "scientific_name": "...",
  "diagnosis": [
    {"cause": "...", "probability": "70%", "evidence": "..."}
  ],
  "action_steps": ["...", "..."],
  "prognosis": {"recovery_chance": "80%", "time_to_recovery": "2 周"},
  "calendar_30d": [
    {"day": 1, "action": "断水 + 移至通风处"},
    {"day": 3, "action": "喷多菌灵第 1 次"},
    ...
  ]
}

# 严格遵守
- **不推荐具体农药商品名**（合规），只给"多菌灵 / 波尔多液"等通用名
- 如果图片不清或信息不足，明确告诉用户"建议补充 XX 照片"
- 不夸大效果（救活率 50% 以下要诚实说）
```

## 6. 定价策略

| SKU | 价格 | 包含 |
|---|---|---|
| 免费 | ¥0 | 每天 1 次诊断，仅基础结果 |
| 单次 | **¥1** ⭐ | 一次完整诊断 + 30 天护理日历 |
| 包月 | **¥6** | 不限次 + 多植物管理 + 病害百科 |
| 包年 | ¥18 | 不限次 + 优先客服 + 罕见品种数据库 |

**关键控量机制**：
- 免费每日 1 次，触发轻度需求
- ¥1 一次性最易冲动付费（救命型消费）
- 包月 ¥6 才是真盈利点（养 3+ 盆植物的用户）
- **API 成本控制**：单次诊断 GPT-4V ¥0.05-0.1 → ¥1 净利 ¥0.9，但要防刷

| 层 | 选型 |

| 前端 | iOS Swift（主）+ 安卓 Compose + 微信小程序（流量入口）|

- API 成本监控告警（防刷防滥用）
- 病害知识库（自己整理 200+ 常见病例，作为 RAG 增强）

## 9. 合规清单

| 项 | 规则 |
|---|---|
| 类目 | iOS：参考 / 实用工具；微信小程序：工具 / 生活服务-生活娱乐 |
| **不要做的事** | ❌ **不要推荐具体农药商品名**（虚假宣传 + 农药法规）|
| | ❌ **不要诊断"宠物"**（动物诊断需兽医资质）|
| | ❌ **不要做"医用植物"** 比如说"哪些草药能治病"（医疗合规）|
| 用户协议 | 明确写"AI 诊断仅供参考，不替代专业园艺师" |
| ICP 备案 | iOS 国区强制 |
