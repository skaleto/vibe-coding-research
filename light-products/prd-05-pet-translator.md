# PRD-05: 宠物心情卡片（原“猜狗翻译器”，极简版 · 试爆款位）

**版本**：v1.0
**日期**：2026-05-27
**调研依据**：[`05-backup-ideas-research.md` § Idea 1](./05-backup-ideas-research.md)
**矩阵角色**：5. 试爆款位（赌博款，不重投入，1 周内完成开发；上架需另留审核 buffer）

---

## 1. 产品概述

### 1.1 一句话定义
录一段猫狗叫声，AI 生成萌系宠物对白 + 可分享朋友圈的"宠物心情卡片"。产品明确是娱乐内容生成，不承诺真实翻译。

### 1.2 定位声明（**重要**）

**这是一个赌博款，定位是**：
- 1 周内开发出可提审版本；正式上架可见需另留 1-3 周审核/整改 buffer
- 押注"病毒爆款"概率（参照 2026-01 "猫咪语言" App 的媒体报道案例；用于方向验证，不当作可复制承诺）
- **接受 7 天留存极低、¥6 包月几乎无续费**
- **不投入推广预算**，靠 ASO + 抖音/小红书自发传播
- **如果 30 天内没爆，立刻放下**（沉没成本严格控制）

### 1.3 验证依据

- **"猫咪语言"App**（2026-01 媒体报道）：2 人团队 + ¥1000 成本，¥1 单次，登顶 App Store 付费榜，单日下载激增 1000 倍
- 中国宠物市场 3126 亿元（2025），养猫人群 7289 万，1.26 亿宠物户
- **但**：应用宝"猫语翻译" 17.7 万下载 / **1.6 分 / 9 条评论**——产品有效性遭普遍质疑
- 用户原话："这不是哄人玩的吗？假的假的" / "猫都听不懂，不理我"

## 2. 目标用户画像

### 2.1 「24 岁刚养第一只猫的小白」（核心）
- **画像**：22-30 岁，租房，养第一只猫/狗 < 6 个月
- **触发**：宠物发出奇怪叫声，想知道"它在说什么"
- **痛点**：完全凭好奇心
- **付费心智**：¥1-3 一次性极易冲动付费；¥6 包月可能买但不续费
- **核心价值**：**娱乐 + 朋友圈炫宠话题**

### 2.2 「想给宠物拍视频的博主」
- **画像**：18-30 岁，刚开始做宠物视频
- **触发**：需要视频素材
- **付费心智**：¥6 包月 OK
- **核心价值**：**素材生产工具**

## 3. 核心用户故事

### 用户故事 1：李同学，24 岁，刚养第一只布偶猫

> 我家"奶油"早上叫了 5 分钟，我录下来上传到 App，¥1 解锁翻译。AI 输出："**奶油说：『主人，我想要肉肉小鱼干！我的饭碗已经空了 3 小时了！』**"，附带一张萌系卡通"奶油 + 对话气泡"的海报。我发到朋友圈，闺蜜们都来评论："你家猫也太能 BB 了"。第二天我又录了 5 次，¥5 全花掉了。

## 4. 功能清单

### 4.1 MVP（**1 周内 ship**）

| 模块 | 功能 |
|---|---|
| 录音 | 大按钮"录下你家宠物的叫声"，15 秒内 |
| AI 翻译 | 输出 **萌系卡通对话**（3-5 句话）|
| 卡片海报 | 一键生成"宠物心情卡片"，可分享朋友圈/小红书 |
| 历史 | 我家宠物的所有"对话" |
| 付费墙 | 免费每天 1 次 / ¥1 单次 / ¥6 包月（不限）|

### 4.2 V2（如果爆了再做）

- 视频翻译（30 秒视频 → 综合表情+声音判断）
- 多宠物管理（猫/狗/鸟/兔子）
- 萌系卡片主题包（5+ 套美学）
- "宠物日记"沉淀（提升留存）

### 4.3 V3+（如果月入 ¥10K+ 再做）

- AI 行为分析（拍 10 秒视频 → "你家猫处于焦虑状态"）
- 喂食/驱虫/疫苗提醒
- 与宠物医院 affiliate（接 referral）

## 5. Prompt 设计（核心：娱乐性 + 不误导）

```
你是一位写宠物萌系绘本的作家。

# 输入
- 宠物种类：{species}（猫/狗/未指定）
- 宠物名字：{name}（用户输入）
- 录音时长：{duration} 秒
- 录音音频特征（可选）：{audio_features}（如：高频/低频/连续/短促）

# 任务
写 **3-5 句** 萌系拟人化对白，把它定位为宠物短视频/朋友圈素材，不要声称能真实翻译动物语言。

# 风格要求
- 萌系、可爱、不要严肃
- 内容可以是：要吃的 / 要玩 / 想出去 / 撒娇 / 抱怨主人 / 看到陌生人警惕等高频场景
- 加入宠物名字让用户感到亲切
- 每段加 emoji，看起来活泼

# 严格遵守
- **声明娱乐性质**：「⚠️ 仅供娱乐，AI 生成宠物心情卡片」必须出现在底部
- 不做严肃的"宠物行为学诊断"
- 不夸大（不能说"翻译准确率 95%"）

# 输出
{
  "translation": ["🐱 主人，奶油又饿啦！", "🐱 你昨晚答应我的小鱼干呢？", "🐱 让我多睡 5 分钟好不好~"],
  "mood_tag": "撒娇 / 求食",
  "disclaimer": "⚠️ 仅供娱乐，AI 生成宠物心情卡片"
}
```

## 8. 技术选型

| 层 | 选型 |
|---|---|
| 前端 | iOS Swift（速度优先）；安卓后补 |
| 后端 | Cloudflare Workers（极轻）|
| LLM | 低成本文本模型（质量够用，单次约 ¥0.005）|
| 音频处理 | 无（只用时长/频率简单特征，不做真识别）|
| 付费 | Apple IAP + 应用宝支付 |

**关键：不要过度工程**
- **不真的做音频识别**（参照"猫咪语言"，预制音效 + 随机）
- **核心是 prompt 设计 + 海报美感**，不是技术
- **1 人 1 周可完成**

**成本极低**：单次 LLM 调用 ¥0.005，¥1 净利 ¥0.99，**毛利 99%+**
