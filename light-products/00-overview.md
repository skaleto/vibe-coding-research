# 轻产品矩阵 · 9 个 idea 调研总览

**调研时间**：2026-05-27
**调研背景**：vibe coding 个人开发者轻产品矩阵（30 App 模式）
**目标市场**：国内为主（微信小程序 + iOS 国区 + 安卓应用宝/华为）+ 可选海外双发
**商业模式**：¥1-198 微付费 + 广告，单产品开发 1-2 周
**调研方法**：按 idea 拆分为 5 份主题调研，覆盖搜索量、竞品、用户痛点、合规与 MRR 推演；收入数据按证据等级处理，不把第三方估算当作官方披露

---

## 0. 决策口径（先看这个）

所有收入 / 下载 / MRR 都按证据强度降权：

| 等级 | 证据类型 | 决策用法 |
|---|---|---|
| A | 官方披露、支付/API 验证、商店后台截图 | 可直接参与排序 |
| B | Sensor Tower / Apptopia / 七麦 / 蝉大师等第三方估算，或媒体采访口径 | 只能作为方向验证，不能当精确收入 |
| C | 平台文章、创始人自述、社区爆款案例 | 只作灵感和假设 |
| D | 匿名截图、二手搬运、无法复核的数据 | 不进入核心判断 |

本文的 MRR 是**模型推演**，不是承诺值；执行前必须用 5-10 个真实用户访谈 + 上架审核可行性 + 小额投放/ASO 测试来校验。

## 三、避坑档案（4 个不推荐 idea 的详细 reasoning）

### ❌ AI 一句话记账（调研评分 2.42 / 5）

**为什么看似 attractive 实则雷点**：
- **用户基数大（>1 亿）但变现极差**：免费白热化竞争
- **巨头垄断**：微信、支付宝、豆包、小米都在做"AI 记账"
- **先驱已倒**：咔皮记账（商汤旗下）半年百万用户全免费 / 网易有钱已停服 / 圈子账本 2022 倒闭
- **AI 自然语言记账已不是壁垒**：咔皮 / Cush / 小贝 / 飞鸭都做了
- **价格上限低**：¥18/年合理但 ¥68 永久偏高，用户群天然抠门
- **D5 护城河 1.5 / D6 抗巨头吞食 1.5**：两个核心维度致命短板

**唯一可考虑的细分**：垂直化路径（AI 情侣账 / 留学生账 / 自由职业者账）—— 但仍需 6-12 月雕琢，不符合矩阵模式。

### ❌ AI 朋友圈文案（调研评分 2.5-2.8 / 5）

**窗口期基本关闭**：
- **豆包月活 3.45 亿**，App 内已原生支持"拍照→朋友圈/小红书/抖音 5 条文案"，免费预装
- **垂直工具红海**：Reditor / XHSPlus / 笔灵 / 7 燕 / 火兔 等已占据小红书工作流
- **平台风险**：小红书 2025 已限流 60 万篇 AI 笔记，2026-05 累计处置 330+ 万篇虚假种草
- **用户痛点本质是"语境坍塌+互动焦虑"**，AI 文案无法治愈，"不发就不发"非刚需
- **C 端付费率仅 9.8%**，订阅极弱；广告（小程序 eCPM ¥20-60）天花板受限
- 中性 MRR 估算仅 ¥5,700

**唯一可考虑的方向**：商家行业垂直模板 / 短视频脚本+分镜 —— 但已超出"轻产品"范畴，更接近 B 端工具。

### 🚫 AI 错题本（K12 合规炸弹）

**致命合规风险**：
- **教育部 2021-12 明文规定**（《关于规范"双减"教育法律服务的意见》等系列文件）：学科类 App 提供者**必须是经民政部门登记的非营利性法人**
- **个人开发者从法律层面无法合规上架**任何 K12 学科类（数学/物理/化学/英语/语文）应用
- 微信小程序个人主体明确禁入"学科类"分类
- 已有大量"作业辅导"小程序被批量下架案例

**唯一可考虑的迂回**：非学科类（音乐/美术/编程入门），但需要内容生产能力 + 不算"错题本"逻辑。

### ❌ AI 古文翻译（被 LLM 直接替代）

- **DeepSeek、豆包、文心一言、Kimi 全部免费支持古文翻译+赏析**，且质量已超过专业古汉语词典 App
- 古诗文网 / 西窗烛 / 古文岛 等传统垂直 App 已沉淀十年内容护城河
- 新进入者**无内容、无成本、无品牌**三无
- 唯一窗口：极小众长尾（如：《说文解字》逐字解析、出土文献释读），但用户基数太小

## 四、推荐 idea 的关键调研发现

### 🥇 AI 起名（最强推荐）

**为什么是它**：
- **三高赛道**：高搜索量 + 高客单 + 高付费意愿
- **5 子产品复用同一脚手架**：宝宝/公司/宠物/网名/笔名
- **竞品价格基线**：起名通 ¥398-9,888 / 美名腾 ¥298-1,698 / App Store 主流 ¥18-58 IAP → 你 ¥68 是甜点价
- **差异化抓手**：真 AI 诗经/楚辞释义 + 美图海报，绕开竞品的"五格剖象评分"老套路

**关键约束**：
- **微信小程序是红线**："算命/八字"被运营规范明确禁止 → 必须走 iOS + 应用宝 + 安卓
- 5 个子产品里：**优先做宝宝起名**（最强需求+最高客单）；游戏 ID 避开（客单 ¥1-9 太低）

**6 月 MRR 推演**：保守 ¥3-8K / 中性 ¥15-30K / 乐观 ¥50-100K。前提是：典故校验可用、付费墙通过审核、至少 5 个目标用户愿意为完整报告付费。

### 🥈 AI 倒数日 Pro

**为什么进入第二**：
- **Days Matter 中国区效率榜 #1，月下载 90 万 / 月入 $60K** —— 这是第三方估算口径，用于验证方向，不代表后排产品可复制
- **监管零**：纪念日/倒计时不触发任何审核红线
- **付费习惯成熟**：用户愿意为"主题/小组件/iCloud 同步"付 ¥6-18
- **天花板有限但稳**：单产品 ¥5-15K MRR 可达

**差异化抓手**：颜值流 + 小组件丰富度（iOS Widget 大、中、小 + 桌面）+ AI 自动从聊天/邮件抓取日期。

### 🥉 AI 植物医生（病害诊断 niche）

**为什么进入第三**：
- **睿琪 PictureThis 验证标杆**：年入 10 亿、月流水 ¥8000 万为媒体报道口径，证明赛道天花板高，但新进入者不能按头部收入外推
- 但**通用识别已被形色/腾讯识花君压制**，新进入必须切 niche

**最佳 niche**：
- "**病害诊断 + 护理日历**"：拍叶子 → 识别病害（病毒、虫害、缺肥）+ 推送护理时间表
- 用户：阳台党、多肉爱好者、绿植新手

**风险**：图像 API 成本高（每次 ¥0.05-0.1），需控制免费额度。

### 4. AI 梦境日记（试水）

**为什么从主推降级到试水**：
- **国内合规需要实测**：微信小程序运营规范 6.1.3 / 6.4.5 / 5.12.15 明确禁止"封建迷信、算命、AI 算命"，不能用主观概率代替审核结果
- **海外被误判数据**：Elsewhere 不是 YC W23 出品（被推翻），是独立小团队，Google Play 仅 5,800 下载；海外赛道严重红海

**仍值得做的理由**：
- 移除"解梦/运势/吉凶"字眼后定位"梦境心理学日记"，挂"心理健康"或"生活记录"赛道，需先用最小包做上架实测
- 海外有 Oniri / DreamApp / Pillowtalk 等头部 ARR $50-500K 区间，证明小盘子可活
- 单产品 1-2 周开发，**轻投入试水合适，不投入重资源**

**国内中性 MRR ¥3-6K / 海外中性 $0.8-1.5K**。

### 5. 宠物心情卡片（原“猜狗翻译器”，试爆款）

**定位**：矩阵中的"赌博位"，卖点从“真实翻译”改为“萌宠对白 + 分享卡片”
- 2026-01 "猫咪语言"App 用 ¥1000 成本登顶 App Store 付费榜为媒体报道口径 —— 证明爆款可能，不代表可复制
- 但**7 天留存极低、内容池有限**，¥6 包月几乎无续费
- 适合作为矩阵中 1-2 个试爆款位（成功了再说，失败成本极低）

## 五、共享脚手架（节省 90% 开发时间）

```
┌─────────────────────────────────────┐
│ 5 屏标准 UI 模板（首页/输入/加载/结果/付费）│
├─────────────────────────────────────┤
│ 统一鉴权 + 付费 SDK（Apple IAP + 应用宝）│
├─────────────────────────────────────┤
│ 统一 LLM 网关（GPT-4o / Claude / DeepSeek 切换）│
├─────────────────────────────────────┤
│ 统一限频 + 防刷 + 错误处理            │
├─────────────────────────────────────┤
│ 统一 ASO 工具链（Sensor Tower / ASOTools）│
├─────────────────────────────────────┤
│ 海报生成模块（每个 idea 都用）        │
├─────────────────────────────────────┤
│ 每个新 App 只改 3 件事：               │
│   • prompt template                  │
│   • UI 文案 + 配色                   │
│   • ASO 关键词                       │
└─────────────────────────────────────┘
```

按此脚手架：**第 1 个 App 工程实现约 2 周，第 2 个约 1 周，第 3 个起 3-5 天**。这只代表开发完成，不包含开发者账号、ICP/备案、IAP 配置、商店审核和整改时间；上架可见需要单独预留 1-3 周 buffer。

## 七、关键决策原则（贯穿 5 个 PRD）

1. **客户访谈先于代码**：每个产品上线前找 5-10 个目标用户聊
2. **合规先于增长**：每个产品先过审核再投入推广
3. **海报美感 = 病毒**：所有结果页必须可一键生成"可分享到小红书的海报"
4. **¥18 / ¥68 / ¥198 三档定价**：覆盖冲动消费、刚需、信仰用户
5. **免费引流 + 付费转化**：不做纯订阅，给免费版才有 ASO 流量
6. **桌面小组件**（iOS）：每个能做的都做，留存翻倍
