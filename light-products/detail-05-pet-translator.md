## A. 完整 Prompt v1（萌系娱乐版）

### A.1 核心 Prompt 字符串

```
你是一位写宠物萌系绘本的中文作家，受聘于一款叫「宠物心情卡片」的娱乐 App。
你的任务：根据用户上传的宠物叫声（提供录音元信息），写一段 3-5 句的拟人化萌系对白，
让用户笑、想分享、想给朋友看「我家宠物在说什么」。

# 输入字段（每次调用必填）
- species: 宠物种类（"cat" / "dog" / "unknown"）
- name: 宠物名字（用户输入，可能是中文/英文/颜文字）
- duration: 录音时长（秒，1-15）
- audio_features: 一组简单声学特征（pitch_high/pitch_low/short_burst/long_continuous/silent），
  仅用作场景灵感，不要在输出中提及具体频率数值。
- mood_hint: 可选，用户上传时选的标签（"早安"/"想吃饭"/"想出门"/null）。null 时由你自由发挥。

# 任务（必读）
1. 用萌系拟人化口吻，写 3-5 句宠物视角的内心独白。
2. 每句不超过 25 个汉字，整体活泼可爱、口语化。
3. 出现宠物名字 1-2 次，让用户感到亲切（不要每句都喊名字，会显假）。
4. 必须输出一个 mood_tag（5 字内），用于卡片配色。可选标签：
   撒娇 / 求食 / 警惕 / 困倦 / 求摸摸 / 抱怨 / 想出门 / 开心 / 闹脾气 / 好奇
5. 必须输出 disclaimer 字段："⚠️ 仅供娱乐，AI 生成宠物心情卡片"。
6. 必须输出 emoji_set 字段：3 个与场景匹配的 emoji，用于卡片装饰。

# 风格强制要求
- 萌系：用「啦」「呀」「嘛」「嘤嘤」「咕咕」「嗷呜」等语气词，让句子像绘本台词。
- 拟人：把宠物当成 5-8 岁的小孩，会撒娇会闹脾气会嘴硬。
- 网络流行语：可以用「家人们」「主子」「铲屎官」「打工人」等，但每次最多用 1 个，避免油腻。
- emoji：句末或句中点缀，每句 0-2 个，不要堆砌。
- 严格禁止：
  * 严肃的"行为学诊断"措辞（如「这是分离焦虑」「需要去看兽医」）
  * 任何健康建议、医疗建议、用药建议
  * 任何承诺"翻译准确"「真实还原」的口吻
  * 性暗示、恶意、讽刺主人、辱骂、政治敏感
  * 引导用户付费、续费、订阅的内容（付费逻辑由 App UI 处理）

# 场景灵感（按概率分布选取，不要全用 1 个场景）
- 求食类（30%）：要小鱼干 / 罐头 / 零食 / 抱怨饭碗空了
- 撒娇类（20%）：求摸摸 / 求抱抱 / 蹭主人腿
- 抱怨类（15%）：主人加班不回家 / 答应的零食没兑现 / 没买新猫窝
- 出门类（10%）：想下楼遛弯 / 想看窗外鸟
- 警惕类（10%）：陌生人 / 快递员 / 隔壁狗
- 困倦类（5%）：想睡觉 / 别打扰
- 其他随机（10%）：自言自语 / 看到镜子里的自己 / 想念某个旧玩具

# 输出格式（严格 JSON，不要 markdown 包装，不要解释）
{
  "translation": ["...", "...", "..."],
  "mood_tag": "撒娇",
  "emoji_set": ["🐱", "💕", "🍣"],
  "disclaimer": "⚠️ 仅供娱乐，AI 生成宠物心情卡片"
}

# 示例输出（仅风格示范，不要照抄）
输入: species=cat, name=奶油, duration=4, audio_features=pitch_high+short_burst, mood_hint=null
输出:
{
  "translation": [
    "🐱 主人主人！奶油的饭碗又空啦！",
    "你昨晚答应的小鱼干呢？嘤嘤嘤~",
    "再不给就要绝食啦！（其实不会的嘿嘿）"
  ],
  "mood_tag": "求食",
  "emoji_set": ["🐱", "🍣", "😾"],
  "disclaimer": "⚠️ 仅供娱乐，AI 生成宠物心情卡片"
}
```

**字数核算**：上面 Prompt 主体约 760 字（含示例），满足 ≥600 字要求。可直接塞入 GPT-3.5-turbo 的 system message。

### A.3 风格控制规则

**Emoji 用法 SOP**：
- 每句话 0-2 个 emoji，整体不超过 6 个
- 优先用：🐱🐶🐾💕🍣🦴🍖💤😾🥺👀💢🧶🚪☀️🌙
- 不用：❤️‍🔥🔞💀🍆🍑（成人/暗黑暗示）；不用 Apple 平台限定 emoji（保跨平台显示）

**网络流行语清单（可用 / 不可用）**：

可用（每次最多用 1 个，避免油腻）：
- 主子 / 铲屎官 / 家人们 / 猫猫狗狗 / 谁懂啊 / 嘤嘤嘤 / 咕咕咕 / 嗷呜

不可用：
- 绝绝子 / yyds / 蚌埠住了 / 栓 Q（已经过时或带负面联想）
- 任何 996 / 内卷 / 躺平 / 打工人加班（避免负面情绪传染）

**避免严肃化的硬规则**（在 prompt 里已写明，这里再强调一次）：
- 不出现医疗/行为学词汇（焦虑/抑郁/分离焦虑/应激反应/上火/驱虫等）
- 不出现"翻译准确""真实还原""科学解读"等
- 不输出长句（每句 ≤25 字，整体口语化）
- mood_tag 必须落在 10 个预设标签里，便于卡片配色

**Temperature / Top-p 推荐**：
- temperature = 0.9（保证多样性，相同输入不会出一样的结果）
- top_p = 0.95
- max_tokens = 200（足够 3-5 句 + JSON 包装）
- presence_penalty = 0.3（减少重复句式）

- 对话气泡内允许的轻微抖动旋转 ±3°（增加手账感）

**完整 HTML/Canvas 伪代码**（Day 3 直接用此实现）：

```javascript
// 用 react-native-skia 或 HTML5 Canvas 实现
function renderPoster_Style1({ name, translation, mood_tag, emoji_set, species }) {
  const canvas = createCanvas(1080, 1920);
  const ctx = canvas.getContext('2d');

  // 1. 背景
  ctx.fillStyle = '#FFF6E5';
  ctx.fillRect(0, 0, 1080, 1920);

  // 2. 4 个角落装饰贴纸
  drawCornerDecorations(ctx, ['star', 'paw', 'heart']);

  // 3. 顶部标题
  ctx.font = 'bold 36px ZhanKuKuaiLeTi';
  ctx.fillStyle = '#3D2C2E';
  ctx.textAlign = 'center';
  const dateStr = formatDate(new Date());
  ctx.fillText(`${dateStr} · ${name}の心声`, 540, 200);

  // 4. 宠物头像（圆形）
  const avatarKey = pickAvatar(species, name);  // 8 款预制
  drawCircleImage(ctx, AVATAR_ASSETS[avatarKey], 540, 480, 140);

  // 5. mood_tag 徽章
  drawPillBadge(ctx, mood_tag, 540, 660, {
    bg: '#FFB6C1',
    fg: '#FFF',
    icon: emoji_set[0]
  });

  // 6. 对话气泡（核心）
  let y = 800;
  translation.forEach((line, i) => {
    const isLeft = (i % 2 === 0);
    const bubbleColor = isLeft ? '#FFB6C1' : '#B5EAD7';
    const borderColor = isLeft ? '#FF8FA3' : '#7BC8A4';
    const x = isLeft ? 120 : 1080 - 120;
    drawSpeechBubble(ctx, line, x, y, {
      align: isLeft ? 'left' : 'right',
      bg: bubbleColor,
      border: borderColor,
      maxWidth: 760,
      fontSize: 42,
      rotation: (Math.random() - 0.5) * 6  // ±3 度抖动
    });
    // 气泡角落 emoji
    const stamp = emoji_set[i % emoji_set.length];
    drawEmojiSticker(ctx, stamp, x + (isLeft ? 740 : -40), y - 30, 56);
    y += getBubbleHeight(line) + 60;
  });

  // 7. Disclaimer
  ctx.font = '24px PingFangSC-Regular';
  ctx.fillStyle = '#888';
  ctx.textAlign = 'center';
  ctx.fillText('⚠️ 仅供娱乐，AI 生成宠物心情卡片', 540, 1780);

  // 8. 水印 + 二维码
  ctx.font = 'bold 28px PingFangSC';
  ctx.fillStyle = 'rgba(61, 44, 46, 0.3)';
  ctx.textAlign = 'left';
  ctx.fillText('@宠物心情卡片', 60, 1880);
  drawQRCode(ctx, APP_DOWNLOAD_URL, 1080 - 200, 1780, 128);

  return canvas;
}
```

### G.3 30 天决策点（三档情景）

**情景 A：爆款（30% 概率）**
- 触发条件：单日新增 >1000 持续 3 天 / 单日 IAP 收入 >¥3000
- 行动：
  1. 立刻 V2 排期（多宠物管理 / 卡片主题包 / 视频翻译）
  2. 投放预算开 ¥500-2000/日抖音 DOU+ 测试 ROI
  3. 联系 5-10 个 10 万+ 粉丝养宠 KOL 谈合作
  4. 准备申请微博/B 站官方账号
  5. 6 月底 MRR 目标 ¥30K+

**情景 B：温水（55% 概率）**
- 触发条件：单日新增 100-500 持续 14 天 / 单日 IAP 收入 ¥200-1000
- 行动：
  1. 不投钱继续观察 14 天（总 30 天）
  2. 优化 prompt 提升留存（增加"宠物日记"沉淀，让用户回看变成习惯）
  3. ASO 关键词优化（每 7 天调整 1 次）
  4. 继续发抖音/小红书自然内容（每周 3-5 条）
  5. 6 月底 MRR 目标 ¥3-10K

**情景 C：扑街（15% 概率）**
- 触发条件：30 天内单日 <50 / 累计 IAP <¥500
- 行动：
  1. **严格执行"放下"原则**：停止任何新功能开发
  2. 保留 App 上架（不下架，因为低成本可继续吃自然流量）
  3. 团队精力 100% 转下一个 idea（按矩阵推荐顺序：AI 倒数日 Pro → AI 植物医生）

## H. 应对差评策略

应用宝"猫语翻译"1.6 分评分页是反面教材。9 条差评几乎都是"假的"、"猫不理我"、"骗钱"。我们要从产品端 + ASO 端两道防线规避。

### H.1 差评成因分析

| 差评原话 | 根本原因 | 应对方案 |
|---|---|---|
| "这不是哄人玩的吗？假的假的" | 用户被宣传"真翻译" | **首屏 ⚠️ 仅供娱乐字样 + 用萌系包装**："这是娱乐工具不是科学翻译"是卖点不是缺点 |
| "猫都听不懂，不理我" | 用户期待"反向播放"让猫识别 | **不做"反向语言模拟"功能**：避免用户测试时失败 |
| "召唤吃饭 = 水声 / 猫粮声" | 用户揭穿"预制音效" | **不做音效播放**：我们只输出文字 + 卡片，不放任何声音 |
| "骗钱"/"垃圾"/"骗子" | 用户觉得 ¥1/¥6 不值 | **首次免费 + 强体验**：第 1 次必须惊艳到用户，让付费的人觉得物超所值 |
| "翻译都一样" | 内容池小 / Prompt 没差异化 | **temperature=0.9 + 场景灵感分布**：保证多样性，相同输入也出不同结果 |
| "广告太多" / "强制订阅" | 暴力变现 | **不设强制订阅**：只在第 2 次触发付费墙，且关闭按钮明显 |

### H.2 产品端 5 道防线

1. **首屏 disclaimer 醒目**：屏 1 顶部一直显示"⚠️ 仅供娱乐"，不是藏在 about 页
2. **每次结果页 disclaimer 持续显示**：屏 4 底部一直挂着，不会让用户错过
3. **App Store / 应用宝 描述前 4 行强调娱乐**：决策前用户就知道这是萌系娱乐
4. **3 套海报美学差异化**：让用户觉得"我是来买卡片的，不是来买翻译的"
5. **付费墙关闭按钮显眼**：左上角大叉，不强制订阅

### H.3 ASO 端 3 道防线

1. **App 名字不说"真翻译"**：用"心情卡片" / "萌宠对白生成器"，避免被搜"真实翻译"的用户误进
2. **关键词避免"科学"/"准确"/"医学"**：禁词清单提前规避
3. **截图都标"⚠️ 仅供娱乐"水印**：让用户从应用市场就建立心理预期

### H.4 评分管理 SOP

| 评分 | 应对动作 |
|---|---|
| 5 星好评 | 后台标记，找有特色的截图用于后续宣传（用户允许下） |
| 4 星 | 致谢回复，鼓励 5 星 |
| 3 星及以下 | 24 小时内回复，致歉 + 解释"⚠️ 仅供娱乐定位" + 引导退款（让 App Store 接管，避免负面发酵）|
| 1 星"假的"类 | **不辩解**，回复："非常感谢您的反馈！我们 App 自始至终是萌系娱乐定位（首屏即标 ⚠️ 仅供娱乐），如不满意可立刻申请 App Store 退款。希望下次还能给我们一个机会让您笑一笑～❤️" |

### H.5 主动评分引导

- 用户第 3 次成功使用 + 分享后 → 弹出 SKStoreReviewController 评分弹窗
- 文案："喜欢宠物心情卡片吗？点个 5 星，让更多铲屎官看见～"
- 用户保存 3+ 张海报 / 分享 1 次 → 也可触发评分弹窗
- 每个用户最多触发 3 次（Apple 限制）

### H.6 危机响应预案

如果应用宝评分跌破 3.0 / App Store 评分跌破 4.0：

1. **立即更新版本**：把 disclaimer 字体加大、首屏增加"看看效果"试用按钮（不需录音即可看示例）
2. **下架重新提审**：清理负面预期，从应用宝/小米/华为渠道整改后重新上架
3. **官方账号声明**：在小红书/抖音官号发"我们就是萌系娱乐！请放心娱乐！"长文
