# PRD：垂直数字模板（简历方向）—— 模板 + 「填表单→自动排版→导出 PDF」轻工具

**文档版本**：v1.0 · 2026-05-30
**作者**：前端工程师（MVP 负责人）
**对应方案**：`light-app-low-ai-2026/deep-dive/03-china-light-app-ideas.md` 方案三（首推：垂直数字模板 / 资料包 + 配套生成小工具）
**一句话**：卖原创简历模板 + 配一个「填表单 → 自动排版 → 一键导出 PDF」的纯前端小工具，纯模板套数据，**运行时零 AI、零后端、零边际成本，一次性买断**；获客靠小红书「产品即内容」（模板美图本身就是种草内容）。

---

## 1. 背景与痛点

### 1.1 用户痛点（强证据）

应届生 / 求职者在做简历时反复踩三个坑：

1. **审美差**：Word 自带模板土、排版乱、字体行距对不齐，HR 第一眼就划走；自己调格式半小时还是难看。
2. **要么订阅、要么贵、要么交付麻烦**：
   - 超级简历 / 五百丁等平台多是**会员订阅制**（连续包月、想导出还要续费），国人普遍厌订阅。
   - 小红书上海量个体卖家卖**裸模板**（Word/PSD 源文件），交付靠**网盘 / 加微信手动发**，买完还得自己往里填、自己排版、自己导 PDF，体验割裂。
3. **跨工具来回倒**：模板在 A，填内容在 Word，导 PDF 又要另存为，换一套模板等于重排一遍。

**核心 Job-to-be-done**：「我想要一份**好看**的简历 PDF，**马上能用**，**不想为它一直付费**，**不想自己折腾排版**。」

### 1.2 付费数据（引子报告，证据强度：媒体 + 多源自报一致）

简历方向是国内创造者经济里**付费意愿被反复验证、且最硬**的细分之一：

- **简历模板 ¥139 × 1.2 万单 = 营收约 ¥160 万**（近乎全利润，零运行成本）。
- 单个 **¥1.88 简历模板累计卖 6.5 万+ 单、单链接成交额超 ¥12 万**（极低客单走量）。
- 大盘：小红书 **#简历模板 浏览 3500 万+**、电子资料笔记 **282 万+**；虚拟商品 GMV **同比增 3.7 倍、94% 是个体店**。
- 教培商家用 **¥1 资料包单月获 5000+ 线索**（资料包当获客钩子已被验证）。

> 结论：简历模板既能走「¥1.88-9.9 低客单引流」，也能走「¥39-139 精品买断」。**付费墙的关键不是「能不能填简历」（那是免费钩子），而是「解锁全部好看模板 + 去水印 + 导高清 PDF」。**

### 1.3 为什么是「模板 + 工具」而不是「纯卖模板」

- 纯卖模板**不需要写代码**，满地宝妈个体户都在卖，没有壁垒、交付还麻烦（网盘 / 手动发）。
- **个人开发者（字节工程师）的不公平优势 = 给模板配一个「自动出成品」的轻工具**：把「买了模板还要自己填、自己排、自己导」变成「在线填表单 → 实时预览 → 一键导 PDF」。
- 这一步**显著提高转化与客单价，且普通卖家做不出来**，形成真壁垒。运行时仍**纯本地确定性逻辑、零云 AI**。

| 人群 | 占比假设 | 特征 / 触点 |
|---|---|---|
| **应届生 / 实习求职** | 60% | 秋招春招高峰、没作品、最在意「模板好看 + 不花钱」、决策快、手机端为主（小红书来的） |

## 3. 功能列表

### 3.1 MVP 必做（P0）

1. **模板选择**：4 套不同风格简历模板（极简灰 / 专业蓝 / 创意彩 / 学术黑），缩略图预览选择，点击即切换。
2. **填表单**：左侧表单（基本信息 / 求职意向 / 教育经历 / 工作经历 / 项目经历 / 技能 / 自我评价），支持多条目增删排序。
3. **自动排版**：表单数据套进选中模板，**自动按 A4 比例排版**；**换模板数据不丢**（数据与模板解耦）。
4. **实时预览**：右侧实时渲染简历，所见即所得（A4 纸张感）。
5. **导出 PDF**：一键导出 A4 PDF（矢量文本优先方案，见技术选型）。
6. **草稿保存**：localStorage 自动存，刷新 / 关页不丢；可清空重填。
7. **付费墙（mock）**：免费版导出**带小水印** + **仅 1 套模板可用**；**¥9 一次买断**解锁全部模板 + 去水印（**mock 支付**，不接真实支付）。

### 3.2 迭代（P1，本周不做，PRD 留位）

- 更多模板（每周上新 1-2 套，作为小红书更新选题）。
- 导出长图（小红书晒图用）。
- 多份简历管理（投不同岗位用不同版本）。
- 一键换配色 / 字号 / 模块顺序。
- 中英双语简历。

### 3.3 明确不做（避坑）

- ❌ **运行时调云 LLM**（如「AI 帮我写自我评价」）：违反「一次买断 + 零成本」的数学，且触发 AI 备案。若要做「智能填充」，只能用**预置文案库 + 模板填充**（确定性，本期不做）。
- ❌ 真实支付 / 账号体系 / 后端：MVP 纯前端，支付为 mock。
- ❌ 简历内容代写 / 简历评分（属内容服务，红线 + 成本）。

## 5. 差异化（卖点三件套）

1. **审美**：原创设计、4 套区分明显的风格、A4 纸张感、HR 第一眼不划走。（审美是该赛道的真壁垒）
2. **一键导出**：填表单 → 实时预览 → 一键 PDF，**全程在线、零跨工具**；换模板数据不丢，可多套对比着挑。
3. **一次买断不订阅**：**¥9 买断**解锁全部模板 + 去水印 + 高清导出，**反订阅心智**直击「厌连续包月」的国人付费习惯；**即买即得**，不靠网盘发货。

> 一句种草话术：「**别买会员了，¥9 买断这套简历模板，填个表单直接导 PDF，HR 看了不划走。**」

| **买断版（主推）** | **¥9（一次性）** | 解锁**全部 4 套**模板 + **去水印** + 高清 PDF；永久有效，**不订阅** |

## 7. 获客（最强项：产品即内容）

### 7.1 小红书选题怎么做

**核心逻辑**：模板美图本身就是内容，发内容 = 获客 = 卖货三合一，规避「做完没人知道」的冷启动死亡谷。

- **钩子选题（标题模板）**：
  - 「应届生免费简历模板，填个表单直接导 PDF📄」
  - 「求职党必存！4 套高级感简历模板（附在线工具）」
  - 「别再买简历会员了，¥9 买断永久用」
  - 「秋招简历 before/after，HR 看了不划走」
- **封面 / 配图**：4 套模板对比美图 + 「填表单 → 实时预览」操作 9 图 + before/after。**模板截图即种草内容**。
- **关键词埋词**：标题 / 正文 / 话题埋「应届生 / 秋招 / 春招 / 简历模板 / 考公 / 实习」高意图词，命中 #简历模板（3500 万浏览）。
- **节奏**：日更 2-6 条，求职旺季（9-11 月秋招、3-4 月春招）加量。

### 7.2 承接与私域

- **挂链承接**：笔记挂链 / 评论区挂链 / 群聊承接到 H5 或小程序。
- **「免费简历模板」钩子**：免费版即可用 1 套 + 导出（带水印），先让用户用起来，导出时 / 去水印时触发 ¥9 买断（教培「¥1 资料包月获 5000+ 线索」已验证钩子模型）。
- **私域沉淀**：引导加微信 / 进群，沉淀复购（每周上新模板 → 老用户回流）。
- **报名小红书独立开发大赛**「宝藏 APP」赛道（配套工具是加分项），博官方流量扶持。

### 7.3 冷启动验证指标（第一周）

先发 3-5 篇带挂链笔记，验证：① 笔记能不能涨赞 / 涨收藏；② 挂链点击 → 进站转化；③ 免费用户 → ¥9 买断转化率。**把「获客」这个最大变量在第一周证伪 / 证实**。

## 8. 技术选型

| 维度 | 选型 | 理由 |
|---|---|---|
| 构建 | **Vite 5** | 对齐既有 mvp 栈习惯，dev 快、build 稳 |
| 框架 | **React 18.3** | 同上 |
| 语言 | **TypeScript 5.5**（strict + `noUncheckedIndexedAccess`） | 对齐既有 tsconfig |
| 样式 | **Tailwind 3.4** + 少量 CSS（A4 纸张 / 打印） | 对齐既有栈 |
| 图标 | **lucide-react** | 既有产品已用 |
| 路由 | 不引入 react-router（**单页编辑器即可**） | MVP 单页足够，降复杂度 |
| **PDF 导出** | **首选 `react-to-print`（走浏览器原生打印 → 另存为 PDF，矢量文本、中文最稳、体积小）**；同时保留 `html2canvas + jsPDF` 作为「直接下载 PDF」兜底方案 | 见 9.1 决策 |
| 状态 / 持久化 | React state + **localStorage**（自写轻封装，含防抖自动存） | 零后端、刷新不丢 |
| 网络 / AI | **零网络请求、零 AI 调用** | 模板套数据是确定性逻辑，纯本地 |

### 8.1 数据模型（简）

`ResumeData`（与模板解耦的纯数据）：`basics`（姓名 / 头衔 / 电话 / 邮箱 / 城市 / 求职意向 / 一句话简介）、`education[]`、`work[]`、`projects[]`、`skills[]`、`summary`。
`TemplateId`：`'minimal' | 'blue' | 'creative' | 'academic'`。
持久化键：`resume:data`、`resume:templateId`、`resume:paid`。
**换模板只换渲染层，`ResumeData` 不动 → 数据不丢。**

## 9. 1 周 MVP 范围

### 9.1 PDF 导出方案决策

- **主方案：`react-to-print`**——调用浏览器原生打印，文本是**矢量**、中文字体渲染最稳、PDF 体积小、对 A4 分页天然友好。用户「打印 → 另存为 PDF / 保存为 PDF」。
- **兜底方案：`html2canvas` + `jsPDF`**——一键**直接下载** `.pdf`（把 A4 预览节点截成图贴进 PDF）。优点是「真·一键下载」、移动端也能存；缺点是文本变位图、体积略大。
- MVP **两者都做**：默认提供「下载 PDF」（html2canvas+jsPDF，最直观一键）+「打印 / 高清」（react-to-print，矢量）。免费版导出强制带水印；买断后去水印。

### 9.2 一周排期（建议）

- D1：脚手架（Vite+React+TS+Tailwind）、数据模型、localStorage 封装、表单骨架。
- D2-3：4 套模板渲染组件（A4 布局）、模板选择 + 实时预览联动。
- D4：表单全字段（多条目增删）、自动排版打磨。
- D5：PDF 导出（html2canvas+jsPDF + react-to-print）、水印逻辑。
- D6：付费墙 mock、移动端响应式、空数据示例。
- D7：自验（build/dev 跑通核心路径）、README、3-5 篇小红书笔记素材。

### 9.3 验收标准

- `npm install && npm run build` 通过（0 error）。
- `npm run dev` 起来后核心路径走通：**选模板 → 填表 → 实时预览 → 导出 PDF**。
- 刷新页面草稿不丢；换模板数据不丢。
- 免费版导出带水印；mock 解锁后去水印 + 全部模板可选。
- 移动端可用（响应式：窄屏表单 / 预览分页签切换）。

## 10. 合规（纯模板无 AI 备案风险）

- **运行时零 AI 生成、零深度合成** → **规避算法备案 / 深度合成新规**，合规最干净。
- **唯一红线在选题与素材**：
  - 模板必须**原创设计**；字体 / 图标 / 配图用**可商用授权**（如开源字体、自绘图标、CC0 素材），**严禁内嵌侵权商业字体 / 图库**。
  - **不卖**「考试押题 / 付费课程盗录 / 破解资源 / 侵权素材」。
  - 不做简历**代写 / 内容生成**（属内容服务，避免红线）。
- 隐私：**用户简历数据全部存本地 localStorage、零上传**，可作为隐私卖点（「你的简历不上传任何服务器」）。
- 收款合规：真实上线走微信小程序虚拟支付 / 小红书店铺，注意主体资质与费率（MVP 为 mock，不涉及）。

## 11. 风险与应对

| 风险 | 等级 | 应对 |
|---|---|---|
| 通用免费模板多、被压价 | 中 | 靠**审美 + 一键导出工具 + 一次买断**差异化，而非拼数量；深耕「应届生」单一人群做到第一 |
| 小红书笔记不起量 | 中 | 第一周低成本测 3-5 篇，证伪就换选题 / 人群，不重投开发 |
| PDF 中文 / 分页渲染问题 | 中 | 双方案（矢量 react-to-print + 位图 html2canvas）兜底；A4 固定宽高比 |
| 字体 / 素材侵权 | 低-中 | 全程开源 / CC0 / 自绘，宣传话术规避「破解」 |
| 真实支付门槛（安卓个人主体受限） | 低 | MVP mock；上线走小红书挂链即买即得 / iOS 内购，费率计入定价 |
