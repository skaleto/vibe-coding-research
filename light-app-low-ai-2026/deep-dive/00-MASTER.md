## 1. 跨场景排序：业余时间最优起手式

按"**痛点真实度 × 付费验证度 × 获客难度（越低越好）× 1周可ship × 你的不公平优势**"综合：

### 🥇 第一档（强烈推荐先做）

**① 国内：垂直数字模板 + 一键生成工具**（综合最优）
- **唯一解决了"获客死亡谷"的方案**：产品本身就是内容，小红书一篇笔记同时完成获客+种草+卖货
- **付费已被硬验证**：简历模板 ¥139×1.2万单=¥160万、滤镜包 ¥38.8万、¥1.88 简历模板累计卖 6.5万单、小红书虚拟商品 GMV 同比 +3.7 倍（强证据，多源）
- **零运行成本**：纯模板套数据 + 端侧"填表→排版→导出 PDF"，不调云 LLM
- **时间窗口**：小红书首届独立开发大赛（¥100万奖金，面向个人/≤10人，给站内流量曝光）
- **业余可行性**：开发难度低（模板 + 简单导出工具）、获客难度全场最低、天花板中（单品可到百万级）
- 1 周 MVP：选"简历"细分 → 做 5-10 套模板 + 一个"填表单自动排版导出 PDF"小工具 → 发小红书 3 篇看转化

**② 浏览器插件：TrustJSON**（时机最稀缺）
- **稀有的"信任真空"窗口**：2026 年 1-4 月装机 200 万+ 的 JSON Formatter 转闭源 + 注入 GiveFreely 捐款弹窗 + MaxMind 硬编码 key 地理追踪上报，HN/Reddit/DEV 引爆，开发者大规模卸载找替代——**这种"需求被外力强行创造"的窗口很少见，且有时效**
- **你的不公平优势**：字节工程师 = JSON 是你每天工具，你就是目标用户
- **冷启动天生强**：Show HN「可信、零追踪、开源的 JSON 查看器」+ 蹭塌房事件，初始流量好拿（冷启动评分 4/5）
- **定价**：核心永久免费抢量 → Pro 一次性 $19-29（diff + JWT + jq + 50MB 大文件），ExtensionPay/Gumroad 收款
- 1 周 MVP：树渲染 + 虚拟滚动（扛大文件）+ 折叠 + 搜索，免费发 HN

### 🥈 第二档（值得做，但各有挑战）

**③ Mac：本地语音听写**（天花板最高，但开发最重）
- 市场体量碾压（语音 AI $22.5B/34% CAGR），Wispr Flow $2B 估值/$10M ARR 验证需求，但**纯订阅 $15/mo + 每句上传**——"本地+买断+隐私"是完美进攻面
- **诚实风险**：不是空白市场，VoiceInk（开源 $25 买断）几乎是"理想答案"，superwhisper/Voibe 也在填。必须押单一聚焦楔子（中英混说 + 技术词汇 + 真私有）
- 开发难度 3/5（系统集成+音频+端侧模型，比纯 UI 重，但有开源参照），天花板 5/5
- **Swift 是唯一选择**（全局热键/文本注入/端侧模型 Tauri 做不好）

**④ 国内：印省省**（一寸照片打印省钱）
- 避开证件照红海，只切下游"排版打印省钱"环节（价差 10 倍是公开痛点，人民网点名"挨宰"）
- "省钱"是天然小红书爆款选题，¥1-3 解锁（学小猫补光灯"免费可用+¥1升级"）
- 天花板低（小钱+流量入口），但获客次低、决策轻

**⑤ 浏览器插件：CleanCSS**（攻击付费龙头缺陷）
- CSS Scan（$69 买断/累计 $100K+）被吐槽"复制出脏 CSS、移动端不稳、无 Tailwind"——做"干净 + 多框架感知输出"
- $39-49 买断卡在 CSS Scan 之下打性价比；但要正面卷输出质量，需持续打磨

### 🥉 第三档（备选 / 练手）

- **Mac：开发者文本流水线工作台**（DevUtils $9 买断/$3-6K MRR 验证，做"多步变形存可重放配方"）— **最适合当 Swift 入门练手**，纯本地最干净
- **Mac：本地划词/截图翻译**（Plae $4.99 刚验证类目，做"划词+截图+PDF+字幕全本地一站式"）
- **国内：本地图片工具箱**（HEIC/压缩/去水印零上传，¥6-12 买断，主打反订阅反广告）
- **浏览器：MyPrompts**（吃 AIPRM 塌房红利，本地优先 prompt 管家）/ **BigJSON Lab**（大文件性能刀）/ **PageKeep**（网页/飞书存档）

## 3. 三条反直觉判断（来自深挖，避免踩坑）

1. **"纯本地/离线"在 2026 已不是护城河**（浏览器/Mac 都一样）——JSON/JWT/正则/听写/翻译都有免费离线版。真护城河是：①蹭新鲜信任事件 ②攻击付费龙头公开缺陷 ③性能/质量做到别人做不到 ④细分人群+审美壁垒。**别再做"又一个通用工具"。**

2. **国内通用工具赛道已被免费产品填满**（Picsew 长截图转免费、小熊倒数免费无内购、通用拼图饱和）——买断空间被压扁。要做就做"有具体省钱/省事闭环"或"有选题/审美壁垒"的细分。

3. **获客 ≠ 技术**，且三场景的获客逻辑完全不同：
   - 浏览器/Mac：靠 **Show HN / Product Hunt 的话题性**（蹭事件、攻击龙头缺陷=天然话题）
   - 国内：靠 **小红书"产品即内容"**（模板类天然适合，工具类要做"省钱"选题）

## 5. 给你的最终建议（字节工程师视角）

**如果只挑一个先做**：看你想验证什么——

- **想最快看到"有人付钱"** → 选 **① 国内数字模板**（获客死亡谷已被产品即内容解决，付费验证最硬，开发最轻；缺点是要会发小红书）
- **想发挥工程师不公平优势 + 全球市场** → 选 **② TrustJSON**（你是目标用户，时机稀缺，Show HN 能爆；缺点是买断单价低需靠量）
- **想要最高天花板、愿意学 Swift** → 选 **③ Mac 本地语音听写**（市场 $22.5B，但开发最重、已有强竞品，需聚焦"中英混说"楔子）

**我的排序建议**：先做 ② TrustJSON 当**练手 + 验证 vibe coding ship 能力**（1 周、你最懂、时机不等人），同时观察 ① 国内模板的小红书选题（开个小红书号试水内容）。两个都是低成本快验证，跑出信号再 all-in。Mac 语音听写作为**第二阶段**（等你练完 Swift 手感、且确认有持续投入意愿再上，因为它最重）。
