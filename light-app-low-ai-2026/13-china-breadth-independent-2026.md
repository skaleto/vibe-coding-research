# 中国大陆轻应用/副业 · 独立广度调研（7 簇机会地图）

**调研日期**：2026-05-31
**定位**：与 Codex 的 `12-china-breadth-pipeline` **并列的独立第二信源**——本文数据全部由 subagent **独立重新检索取数**，不依赖任何二手汇总结论，与 Codex 形成**交叉验证**而非复用。
**方法**：并发工作流，7 个 general-purpose agent 各覆盖一个本土场景簇 + 蒸馏。
**证据分级**：A=官方/支付/商店后台/并购；B=媒体/七麦/蝉大师/新榜/访谈；C=创始人自报/社区爆款；D=匿名搬运/仅产品页。
**与 Codex 的关系**：已知 Codex 纵深覆盖了「小红书生成器 / 闲鱼二手 / 本地小店团购 / 创作者质检 / 长辈照护 / 飞书企微模板」——本文用"7 簇横向地图"角度独立铺开，重叠处(闲鱼/本地小店/飞书)为独立交叉验证，其余为补充。

> ⚠️ 中国大陆收入数据**几乎无 A 级公开**(无商店后台/支付验证可查)，主力是 B/C 级 + 代理指标。凡 C/D 级一律按"可能注水"对待，**严禁当基线**。头部百万案例全是幸存者偏差。

## 0. 三条改写格局的中国大陆硬约束（先钉死）

1. **iOS 小程序虚拟支付破冰的真实门票**(A 级官方)：2026-03-15 起 iOS 费率 15%→**12%**(全为苹果佣金，腾讯 5% 技术费 2026 暂免)；2026-04-01 起虚拟交易强制走虚拟支付。**但🚨个人身份证主体=微信支付/虚拟支付全部禁用、严禁任何模拟支付UI**；只有**企业/事业单位/个体工商户**能开。→ **红利门票 = 办一张个体工商户执照 + 300 元/年认证**(线上可办、无注册资本)。对有技术背景的你是 ≈1 天的低成本行政门槛，但**必须先办，否则"¥1-18 解锁"商业模式本身不合规**。
2. **个人做"AI 运行时"被深度合成备案 + 企业主体堵死**——只能走**纯本地/确定性/数字商品**路线(与海外可自带 Key 套壳不同)。
3. **2026 起平台按季向税务报送经营者收入**，多渠道合并计税——收入对税务透明，需如实申报。

**贯穿性结论**：① 流水≠净利(9.9 元客单要扣 iOS 12% + 获客人力/投流)；② **分发是唯一真壁垒**，纯工具被动流量趋零("3 个月赚 6.18 元"是基线，非段子)；③ 微信搜索对小主体几乎零权重、平台级 ToB 入口(钉钉 10 万保证金、企微服务商资质)对个人关门 → 只能靠**"产品即内容"(小红书/抖音) + 私域 + 个人 IP**。

## 3. 脑暴点子（每簇精选，规避 Codex 已覆盖选题）

- **数字商品**：① 窄职业"确定性数字成品"——公考答题模板/自动记账快捷指令+飞书表/护士排班表，把工具工程化(卖工具比卖单张模板溢价 10-20 倍)；② 把"工具"做成数字商品模板包绕开纯工具被动流量陷阱。
- **本地确定性工具**：① **考公/考研/教资证件照规格救急包**(锚定报名季精确像素/底色/KB 校验)；② **纯本地 PDF/文档急救箱**(小程序端本地处理,"文件不上传"是卖点);③ **行业专用确定性计算器**(装修估价/税费/宠物用药剂量,"省钱防坑出报告"型,远离医疗金融敏感类目)。
- **闲鱼/本地小店**：① 闲鱼虚拟商品卖家的**本地化自动发货+话术/合规助手**(卖铲子)；② 极垂直**多平台收款对账工具**(纯确定性零AI不碰资金不需牌照,避开支付牌照+备案两道墙)；③ 长尾垂类(宠物店/教培)**轻预约+核销**(避开美业餐饮红海,但B端地推获客极慢)。
- **垂直行业**：① 窄职业**合规台账+排班/报价飞书模板包+快捷指令**(产品即内容)；② 行业**合同/文书模板+在线填充工具化**专栏(需免责声明)。
- **出海+知识付费**：① **用户自带 Key 的零运行时 AI 成本垂直工具**收美金(build-in-public 投 6-12 月)；② 卖给"想出海的中国开发者"的**中文铲子**(获客回落即刻/X 中文)；③ 跑出可晒数据后**二阶变现**为付费专栏/社群(顺序不可颠倒)。

## 5. 中国大陆相对海外的结构性差异（独立验证结论）

- **变现**：国人厌订阅、偏一次性买断/低价解锁/数字商品 → 小红书买断、星球买断顺人性,订阅制(小报童)更难卖；海外可订阅、可自带 Key 套壳。
- **合规**：① iOS 12% 破冰但门票是个体户执照+300元/年,个人身份证主体收款全禁；② 个人 AI 运行时被深度合成备案堵死,只能纯本地/确定性/数字商品；③ 收入对税务透明。
- **分发**：海外靠 SEO/X/PH/HN；中国靠"产品即内容"(小红书/抖音)+私域+个人 IP；微信搜索对小主体几乎零权重、平台级 ToB 入口对个人关门。

## 6. 给字节背景工程师的 3 条路径（广度收口）

1. **【起手·国内】个体户主体 + 窄职业"确定性数字商品/模板/快捷指令"**——小红书产品即内容 + 私域。满足"零运行时 AI + 快速 ship + 吃 iOS 12% 红利";技术优势=用 LLM 批量造 SKU、把工具工程化(卖工具比卖单张模板溢价 10-20 倍)。基线小钱,护城河=持续上新+IP。
2. **【高天花板·海外】自带 API key / 纯本地确定性工具收美金**(Tony Dinh 模式,AI 成本结构最优,天花板 $1M+ ARR)。把 build-in-public/分发当第一性问题,否则掉进"500页零排名"坟场。
3. **【二阶变现】用 1 或 2 跑出的可晒数据 → 卖中文铲子 + 开付费专栏/社群**。顺序不可颠倒——B 是 A 的下游,没有实绩的专栏必入长尾。

**一句话**：技术是你最不缺的；先用确定性工具/数字商品在国内或海外跑出一个可晒的小成绩,把"分发与个人 IP"当成第一难题,再做高毛利二阶变现。
