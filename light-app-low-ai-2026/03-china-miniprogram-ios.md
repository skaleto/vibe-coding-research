# 国内"运行时零/低 AI 依赖、一次性买断"轻应用机会调研

**调研时间：2026-05**
**调研范围**：微信小程序工具 / iOS 国区一次性买断 App / 国产浏览器插件 / 数字工具与模板（创造者经济）
**目标读者**：个人开发者，想用 vibe coding 做"运行时纯本地逻辑、零/极低 API 成本 + 国内一次性买断付费"的轻应用

> **核心结论先行**：
> 1. **运行时纯本地的工具确实更适合一次性买断**——补光、证件照、去水印、计时、OCR、相机滤镜这类"算法在端上跑、不调云"的工具，没有持续 API 成本，¥1-18 买断/解锁的边际利润几乎 100%，且契合国内"讨厌订阅、喜欢一口价"的付费心理。
> 2. **但"纯工具一次性买断"在国内更多是"小钱生意"**：APP 直接收入普遍是**几百到几万/月**量级，能跑到月入数万的几乎都叠加了"个人品牌 / 广告流量主 / 订阅"。真实失败案例非常多（"6 年只赚 180 块""上了 App Store 首页推荐仍月入不足 3000"）。
> 3. **2025-11 政策重大变化**：苹果与腾讯达成协议，微信小程序/小游戏正式接入 iOS 端虚拟支付，**总费率约 17%**（苹果+腾讯），腾讯技术服务费 2026 年限时减免。这把"小程序内 iOS 一次性解锁付费"从过去的灰色地带变成了合规可走的路——是本轮最值得关注的窗口。
> 4. **最可行的个人路径**：选一个**纯本地、刚需、决策轻**的工具（证件照/补光/去水印/计时/OCR），定价 ¥1-12 一次性解锁或"免费+一次性升级"，靠小红书/抖音内容获客，把"收费"本身做成话题。

## 第一部分：政策与付费习惯现状（先看规则）

### 1.1 小程序虚拟支付政策：iOS 端 2025-11 正式破冰（最关键更新）

历史上苹果长期禁止 iOS 微信小程序内做虚拟商品/解锁的内购（怕小程序生态绕过 App Store 抽成）。开发者过去只能在 iOS 小程序里走"广告流量主"或诱导用户去外部 H5/公众号付费，体验差且违规风险高。

**2025-11-13 转折**（证据强度：媒体，多家一致）：
- 苹果与腾讯达成协议，苹果将处理微信小游戏与小程序中的支付，并从中抽成；同步推出"小程序合作伙伴计划"(Mini Apps Partner Program)，部分开发者 App Store 抽成由 30% 降至 **15%**。
- 微信官宣：小程序/小游戏将在 **iOS 端支持接入虚拟支付**，标准总费率约 **17%**（含苹果与腾讯两部分服务费）；为激励开发者，**腾讯的技术服务费 2026 年限时减免**。
- 来源：[21 世纪经济报道](https://www.21jingji.com/article/20251114/herald/e7a9317efd72df99d27a5ead2c65713b.html)、[IT 之家](https://www.ithome.com/0/897/349.htm)、[北京商报](https://www.bbtnews.com.cn/2025/1118/576233.shtml)。

**对个人开发者的含义**：以前"工具小程序在 iOS 上想做一次性解锁付费"几乎走不通，只能靠安卓内购 + iOS 广告；现在 iOS 端虚拟支付合规开放，**"一次性 ¥1-18 解锁高级功能"在双端都能做了**，是本轮最实在的红利。注意：安卓端微信小程序虚拟支付一直需要单独申请开通（个人主体能力受限，常见报错 `requestPayment:fail banned` / "小程序支付能力已被限制"），开通门槛与主体资质相关。

### 1.2 主体与上架门槛
- 微信小程序：注册免费，**个人主体每年认证费 30 元**（非个体工商户类目）；商业类目/虚拟支付需企业或个体户主体，个人主体可经营范围受限。来源：[微信开放社区](https://developers.weixin.qq.com/community/develop/doc/000c6030030c989ef9cf0d82c51000)。
- iOS：苹果开发者会员 **$99/年**；国区 2026-03 起对符合条件的小开发者抽成可降至 15%（小型开发者计划）。来源：[17173 转述](https://news.17173.com/content/03132026/185109155.shtml)。

### 1.3 一次性买断 vs 订阅：国内付费习惯
- **用户侧明显偏好一口价买断**：知乎/少数派多篇讨论指出，国人对订阅制抵触强（"不付费就失去使用权""损失厌恶被胁迫感"），更接受"买断+大版本更新"。来源：[爱范儿](https://www.ifanr.com/app/1248797)、[知乎"为什么国人不接受月付订阅"](https://www.zhihu.com/question/13807081699)。
- **开发者侧的两难**：买断在大版本发布初销量见顶、之后长期低收入间期；订阅 LTV 更高（有研究称订阅模式利润比买断高约 217%）。来源：[少数派"再回看订阅制"](https://sspai.com/post/57602)。
- **结论（对运行时零/低 AI 工具尤其成立）**：纯本地工具**没有持续成本**，买断的"长期低收入间期"问题被"零边际成本+靠新用户增量"对冲；加上国人偏好一口价，**¥1-18 一次性解锁是工具类小程序/轻 App 的甜点**。订阅更适合"有持续更新/持续服务"的重工具（如 OCR 全家桶、记账云同步）。

## 第二部分：真实案例（11 个，按品类）

> 证据强度标注：**媒体**（第三方报道）/ **创始人自报**（开发者本人公开）/ **第三方**（榜单/统计）。许多精确收入"未公开"，标注 traction。

### A. iOS 国区一次性买断 / 轻付费 App

**案例 1｜小猫补光灯（CatLight）——纯本地补光工具，¥1 Pro 登顶付费榜**
- 入口：iOS App Store（"摄影与录像"类）。开发者陈云飞（花叔）。
- 痛点 + 用户：小红书爱拍照人群在餐厅/清吧/剧院/机舱等暗光场景补光；替代"下载补光图片+手机当灯"的繁琐操作。纯前端"屏幕显色补光"，**运行时零 AI、零服务器、零 API 成本**（典型纯本地逻辑）。
- 数据：免费版上线**约 10 天下载破 3 万**；冲入 iOS 总榜/摄影类 Top20。半个月后推出 **Pro 版定价 ¥1**，很快冲到**付费榜第一**。两款 App 累计下载近 20 万。媒体按"20 万下载 × ¥1 × 70%"估算**直接收入约 ¥14 万**（粗估）。证据强度：**媒体 + 创始人自报**（[36氪](https://eu.36kr.com/zh/p/3260888901418760)、[搜狐](https://www.sohu.com/a/830224486_121798711)、[掘金](https://juejin.cn/post/7474872585412821002)、[知乎"一元登顶"](https://zhuanlan.zhihu.com/p/2022344614066024769)）。
- 变现模式：**免费版可用 + ¥1 一次性升级 Pro**（关键："付费版是升级而非解锁"，免费版必须能用）。无一分钱广告投放，把"开始收费"做成小红书/即刻话题，反而带动下载。
- **重要纠偏**：陈云飞离职后年入接近百万，但**App 本身收入只占最小一块**，大头是"App 口碑→个人品牌→咨询/商单/课程/企业定制"。即"纯工具买断"撑起的是**流量入口与个人 IP**，不是直接现金牛。
- 个人可行性：**极高**（1.5 小时 Cursor 做出 MVP），是 vibe coding + 纯本地工具的标杆样本；但要复制其收入需配套个人品牌运营。

**案例 2｜NOMO 相机——胶片滤镜，¥6/相机买断 + 订阅，苹果年度本土 App**
- 入口：iOS App Store（NOMO / NOMO RAW）。开发者林嘉澍（flypig，灵光闪现科技）。
- 痛点 + 用户：复古胶片质感拍照、刷屏朋友圈的"仪式感"相机。滤镜本地渲染为主。
- 数据：曾刷爆朋友圈，获苹果**2018 年优秀本土 App**。具体营收**未公开**，但长期位列摄影付费榜、口碑级 traction。证据强度：**媒体**（[极客公园](https://www.geekpark.net/news/303164)、[爱范儿](https://www.ifanr.com/app/1064620)）。
- 变现模式：**分层**——单个相机滤镜 **¥6 一次性买断** + 订阅（解锁全部相机）。是"买断打底 + 订阅增值"的经典混合范式。
- 运行时 AI：基本无云 AI（本地滤镜/胶片模拟）。
- 个人可行性：中。滤镜美学与品牌是壁垒，技术不难，但"做出刷屏审美"靠运营与设计功力。

**案例 3｜白描——OCR 文字识别 / 文件扫描，多端工具**
- 入口：iOS / Android / Windows / macOS / 网页 / 小程序。
- 痛点 + 用户：拍照取字、读书做笔记、文档扫描转文字；初衷是作者给女友做的轻量 OCR。
- 数据：长期居 iOS 效率类前列，多端覆盖、口碑稳定；精确营收**未公开**。证据强度：**媒体**（[少数派](https://sspai.com/post/75705)）。
- 变现模式：**会员制**（除小程序外多端通用会员）——属"持续更新的重工具"，更偏订阅/会员而非纯买断。
- 运行时 AI：OCR 引擎可端侧/云端混合（识别能力强时通常有云端环节，**非"零 AI"纯样本**，列此作"工具类天花板"参照）。
- 个人可行性：中。OCR 自研门槛高，但可基于成熟引擎/系统 VisionKit（端侧）做轻量版做差异化。

**案例 4｜貔貅记账——¥38/年订阅，月营收约 ¥4 万（订阅反例对照）**
- 入口：iOS App Store。开发者王维东。
- 数据：以 **¥38/年订阅**，**月营收约 ¥4 万**；目标 3 万持续付费用户→年入百万。证据强度：**媒体引述创始人**（[CSDN 转述](https://blog.csdn.net/liushuliushi/article/details/135767874)）。
- 价值：**订阅样本对照**。记账"持续记录+云同步"天然适合订阅；但同时也说明国内订阅工具要到"几万付费用户"才年入百万，**获客是真瓶颈**。
- 运行时 AI：传统记账逻辑本地为主（云同步），非 AI 依赖。
- 个人可行性：中低（记账红海，留存/同步/品牌门槛高）。

**案例 5｜SideProject / FlipTimer / DDLTodo / Crop & Grade——一人 4 款工具，"赚回会员费"**
- 入口：iOS App Store。某 AI 独立开发者（少数派《回本了：我的 2024 年 AI 独立开发者之旅》）。
- 数据：用 Cursor + Claude/GPT 做了 4 款工具（副业追踪、翻盖计时器、极简待办、照片裁切）；第一年约 **$40** 收入，2024 年达成"**赚够苹果 $99 年费**"的回本目标，绝对金额很小。证据强度：**创始人自报**（[少数派](https://sspai.com/post/95325)）。
- 价值：**真实"小钱样本"**——纯工具买断/低价能跑通"不亏钱"，但要靠 ASO/小红书做增长才有想象空间。计时器/待办本身**运行时零 AI、零成本**。
- 个人可行性：高（门槛极低）；收入天花板取决于获客。

### B. 微信小程序工具（一次性付费 / 广告）

**案例 6｜证件照小程序——¥9.9/张一次性付费，单量大时日入数千**
- 入口：微信小程序（"证件照"是千万级搜索指数关键词）。多家独立开发者/源码生态。
- 痛点 + 用户：考公/求职/签证等急需标准证件照、换底色、排版打印；**决策极轻、即时刚需、愿意一次性付费**。证件照裁剪/换底色可纯端侧或轻量服务端实现，**基本零/极低 AI 成本**（换底色用抠图算法，可端侧或便宜模型）。
- 数据：自媒体/源码方自述"客户做一种模式付 **¥9.9**，跑 1000 单/日 ≈ **¥1 万利润/日**""**日收益保守 ¥3000-8000**"；并衍生**分销代理**（代理费 ¥399/499/899）。证据强度：**创始人/自媒体自报**（[知乎"证件照小程序日赚两千"](https://zhuanlan.zhihu.com/p/716261754)、[V2EX 700856](https://www.v2ex.com/t/700856)）——数字偏营销口径，**需打折看**，但"按张一次性付费"模式真实成立。
- 变现模式：**¥9.9 一次性付费导出/解锁** +（部分）分销。
- 个人可行性：高（技术简单、模板多），但**已是红海且打价格战/分销裂变玩法重**，纯靠产品很难突围，更多靠投流/分销/SEO。

**案例 7｜去水印类小程序——纯前端工具，广告流量主月入 ¥300-1000**
- 入口：微信小程序（短视频/图片去水印）。多家独立开发者。
- 痛点 + 用户：去除抖音/快手/小红书短视频与图片水印、保存素材。处理可纯前端/轻服务端，**运行时零 AI**。
- 数据：某"简洁去水印"小程序累计访问 **2.4 万+**、日活约 **500**，**纯靠激励广告月入约 ¥300-1000**。证据强度：**创始人自报**（[V2EX 873234](https://www.v2ex.com/t/873234)、[博客园评测](https://www.cnblogs.com/newjpz/p/19414426)）。
- 变现模式：以**激励视频广告流量主**为主（"看一次广告免费用"），少数做会员。说明**广告变现需要大流量**才有意义。
- 个人可行性：高（纯前端、模板成熟），但**头部免费产品多、同质化严重**，靠广告很难赚大钱；可考虑"基础免费 + 批量/无广告一次性解锁 ¥1-6"。

**案例 8｜工具集合类小程序 / 自运维 3 年小程序——长尾小钱**
- 入口：微信小程序（计算器/单位换算/工具箱合集等纯前端工具）。多位 V2EX 开发者。
- 数据：典型工具类小程序"**月收入 ¥1000-10000**"（行业口径）；但也有大量"**做了 6 年只赚 180 多块、还要交 300 认证费**""自运维 3 年送会员"的长尾案例。证据强度：**创始人自报 + 行业统计**（[V2EX 1039459](https://www.v2ex.com/t/1039459)、[V2EX 1002311](https://www.v2ex.com/t/1002311)、[知乎"如何用小程序赚钱"](https://www.zhihu.com/question/280264248)）。
- 变现模式：广告流量主（UV≥1000 可开通，<100 万流水 5:5 分成）+ 少量一次性解锁/会员。来源：[微信开放社区流量主分成](https://developers.weixin.qq.com/community/develop/article/doc/000acc910cc118d79cb9fd5e458c13)。
- 个人可行性：高，但**纯工具合集做大很难**，更多是练手/长尾被动收入。

### C. 浏览器插件（含国产）

**案例 9｜沉浸式翻译（Immersive Translate）——国产插件，200 万+ 用户**
- 入口：Chrome / Edge / Firefox / 油猴脚本。国内独立开发者 Owen 主导。
- 痛点 + 用户：网页双语对照翻译、PDF/电子书翻译，效率人群刚需。
- 数据：Chrome 商店用户**突破 200 万**、评分 4.4，被 Google 评为 **2024 年度最受欢迎扩展之一**。证据强度：**媒体**（[知乎](https://zhuanlan.zhihu.com/p/1969456069723009530)）。
- 变现模式：**Freemium**——基础免费，Pro/高额翻译额度付费；**可接入用户自带 API key**（把 AI 成本转嫁给用户，开发者侧"低 AI 依赖"）。这是"低 AI 成本"的聪明设计：**让用户填自己的 key**。
- 运行时 AI：翻译本身依赖翻译/LLM API，但**支持 BYOK（自带密钥）**，开发者可不承担推理成本。
- 个人可行性：中（翻译壁垒在工程细节与生态），但"BYOK + 一次性/订阅 Pro"的成本结构值得借鉴。

**案例 10｜CSS Scan / Spider——买断制 Chrome 工具，$69 / $38**
- 入口：Chrome Web Store（海外为主，模式可借鉴国内）。
- 数据：**CSS Scan**（查看/复制网页 CSS）月入 **$100,000+**，**买断 $69**；**Spider**（可视化爬虫）两个月 **$10,000**，**买断 $38**。证据强度：**第三方汇总博客**（[博客园"8 个赚钱的 Chrome 扩展"](https://www.cnblogs.com/jiaoran/p/16264753.html)）。
- 变现模式：**纯一次性买断**（开发者工具人群接受买断）。运行时纯本地、零 AI。
- 个人可行性：中。开发者工具客单价高、付费意愿强，是"买断制纯工具"的良性样本；国区可类比"效率插件买断"。

**案例 11｜ReaderMode——周末做的阅读插件，两年累计 $40,000**
- 入口：Chrome Web Store。马来西亚独立开发者 Ryzal。
- 数据：发布 24h **$2000**；发布两周 **5000 用户**（零成本）；8 个月累计 **$1 万**；两年多累计 **$4 万**。证据强度：**创始人自报**（[掘金](https://juejin.cn/post/7229126088227962936)、[V2EX 938769](https://www.v2ex.com/t/938769)）。
- 变现模式：Freemium（基础免费 + 高级订阅，含 AppSumo 等 deal 平台）。MVP 仅一个周末。
- 个人可行性：高（极轻、纯本地阅读增强），是"1-2 周可 ship + 慢热增长"的典型。

### D. 数字工具 / 模板（创造者经济，天然规避运行时 AI 成本）

**案例 12｜Easlo——卖 Notion 模板，3 年 $50 万+**
- 入口：Gumroad 独立站 + Twitter/社群（海外，国内可类比知识星球/小报童/模板店）。
- 数据：新加坡开发者 Easlo，3 年多卖出 **62 万+** 份模板，累计 **$50 万+**（约 ¥350 万+）；做了 30+ 款模板，定价 **$0（免费引流）-$299**；Twitter 31.3 万粉。证据强度：**媒体**（[不上班研究所](https://www.toocool.cc/p/1967)、[掘金](https://juejin.cn/post/7351734240851427343)）。
- 变现模式：**纯一次性买断数字商品**——**零运行时成本、零服务器、零 AI**，是"规避 AI 成本"的极致形态。
- 国内映射：知识星球/小报童付费专栏、Notion/飞书多维表格模板、小红书卖模板/资料包、效率工具配置包等，均是"做一次卖多次、零边际成本"的一次性买断生意；**最契合"怕烧云 LLM 钱"的诉求**，且 vibe coding 可快速产出配套小工具/落地页。
- 个人可行性：高（无需服务端），核心是选题 + 流量/SEO/社群运营。

## 第三部分：横向洞察与给个人开发者的结论

### 3.1 "运行时零/低 AI"的工具天然适合一次性买断
补光、证件照、去水印、计时/番茄钟、相机滤镜、阅读增强、Notion 模板——共同点是**逻辑在端上跑或一次性交付**，没有持续 API/推理成本。买断/一次性解锁的边际利润≈100%，叠加国人"讨厌订阅"心理，**¥1-18 一次性解锁是甜点定价**。需要持续服务的（OCR 全家桶、记账云同步、翻译额度）才考虑订阅/会员，或用 **BYOK（让用户自带 API key）** 把 AI 成本转嫁出去（沉浸式翻译范式）。

### 3.2 收入真相：纯工具买断在国内多是"小钱 + 入口"
- 直接收入：小程序工具普遍 **月入 ¥300-10000**；iOS 工具买断多在**几千到几万**；能到月入数万/年入百万的，几乎都叠加了**个人品牌（小猫补光灯）/ 大流量广告 / 订阅（貔貅记账）/ 分销（证件照）**。
- 失败是常态："**6 年赚 180 块**""**App Store 首页推荐仍月入不足 3000**""80% 独立开发者月入低于 ¥1 万"——证据强度均为创始人自报/行业统计（[woshipm](https://www.woshipm.com/pd/6198096.html)、[CSDN 生存现状](https://blog.csdn.net/FansUnion/article/details/148829546)）。
- **正确预期**：把纯工具买断当作"**低成本、快验证、可能的小钱 + 个人 IP 入口**"，而非一夜暴富。

### 3.3 最值得个人开发者下手的组合（1-2 周可 ship）
1. **纯本地刚需工具 + ¥1-12 一次性解锁/升级**：证件照、补光、去水印、计时/纪念日、图片压缩/格式转换、本地小工具。借鉴小猫补光灯"免费可用 + ¥1 升级"而非"硬解锁"。
2. **双端发**：iOS（买断/解锁）+ 微信小程序（2025-11 后 iOS 虚拟支付已开放，¥1-18 解锁可双端做）；安卓小程序虚拟支付需注意主体/开通门槛。
3. **获客是真壁垒**：把"收费/产品故事"做成小红书/即刻/抖音内容（小猫补光灯打法）；或做开发者工具走 V2EX/即刻口碑。
4. **零运行成本的退路**：Notion/飞书模板、知识星球资料包、效率配置包——纯数字商品一次性买断，**完全规避服务器与 AI 成本**，适合先验证选题与流量。
